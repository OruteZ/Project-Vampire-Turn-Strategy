## 1. 공통

> 2026-11-07 (#34): 보드 카메라는 이제 화면 전체를 그린다. 보드만 보드 영역 안에 맞춘다 (docs/art/stage-dressing.md 1-4). 아래 "같은 색으로 지운다"는 메뉴 배경 RT 에만 해당한다.

1. 기준 해상도 1920×1080, 안전 여백 24px, 보드 영역은 위 150·아래 190·왼쪽·오른쪽 360 을 뺀 가운데 (ui-style.md 1).
2. 보드 카메라는 화면 전체에 그리고 바탕은 `bg.night` 로 맞춘다. 보드가 보드 영역 안에 들어오게 카메라 위치·거리로 맞춘다. 보드 영역 경계에 사각형이 보이면 안 된다.
3. 한 화면의 1단계 요소는 5개 이하 (ui-style.md 3).
4. 위협 범위는 어떤 단계에서도 칠하지 않는다 (ui.md). 적을 살펴볼 때도 칠하지 않는다.
5. 모든 화면 문장은 `Text` 표 키로 쓴다 (docs/ui/localization.md). 7절에 새 키를 적었다.
6. 후속 (#43, ui-style.md 15·16): 캔버스가 Expand 로 바뀐다. 이 화면의 칸은 이미 모서리·변에 붙은 고정 크기라 배치는 그대로다. 4:3·5:4 에서는 화면 전체가 0.75·0.667 배로 작아지고 위아래 빈 곳이 늘어난다. 구현 때 `tools/ui-audit/sweep.sh` 로 배치·아군 턴·규칙·기록·결과를 6개 화면비에서 다시 확인한다. 보드 영역(1번)은 보이지 않는 틀이라 stretch 그대로 둔다 (15-3 예외).

### 2-2. 편성 패널

1. 병종마다 `btn.roster` 한 줄 (높이 64): 왼쪽 병종 무기 아이콘 40px (ui-style.md 9), 이름 `body` Bold, 오른쪽 비용 "인구 {n}" (은이 들면 " · 은 {n}") `small`, 아래 줄에 수치 "체력 {hp} · 공격 {atk} · 방어 {def} · 이동 {mov} · 사거리 {rng}" `small` `text.2`.
2. 고른 병종은 선택됨 상태(ui-style.md 6 상태). 처음에는 목록 첫 병종이 골라져 있다.
3. 인구나 은이 모자라 놓을 수 없는 병종은 비용 글자를 `enemy` 로. 고를 수는 있다 (놓을 때 거절 안내가 뜬다, 지금 동작).
4. 목록 아래에 `small` `text.3` 도움말 한 줄: "빈 칸을 눌러 배치. 끌어서 옮기거나 바꾸고, 구역 밖으로 끌어내면 회수."
5. 맨 아래 `btn.normal` 둘: "모두 회수", "예시 편성".

### 2-3. 배치 보드

1. 배치 구역 칸: 테두리 `ally` 2px, 채움 `ally` 8% (ui-style.md 8-2 이동 칸과 같은 모양).
2. 끌기·바꾸기·회수 동작은 지금 그대로.
3. 배치 중에도 적을 호버하면 오른쪽 아래 유닛 패널에 그 적이 뜬다. 칠하지는 않는다 (1-4).

## 3. 아군 턴

배치는 목업과 같다 (ui-style.md 10). 이 절은 목업에 없거나 다른 것만 정한다.

### 3-1. 머리

| 자리 | 요소 | 단계 |
|---|---|---|
| 왼쪽 위 | 전황 넷: 턴, 아군, 적(스폰 뺌), 스폰. 스폰 숫자 뒤에 시신이 있으면 " +{시신 수}" (`spawn`). 숫자 `num.2`, 이름 `small` `text.2`. 숫자 색: 턴 `text.1`, 아군 `ally`, 적 `enemy`, 스폰 `spawn` | 2 |
| 위 가운데 | 보름달 게이지. 아군 페이즈에 달이 내려가면(장의사 성스러운 매장, #99) 바로 새 값으로 바뀌고, 다음 적 턴이 보름달이 아니게 되면 "다음 턴 보름달" 상태·표적 선도 바로 사라진다 (ai.md 5-2) | 1 |
| 오른쪽 위 | 전투 기록 (3-5) | 2·3 |

### 3-2. 유닛 패널

1. 왼쪽 아래 = 아군 패널: 선택한 아군. 선택이 없으면 호버한 아군. 둘 다 없으면 숨긴다.
2. 오른쪽 아래 = 적 패널: 호버한 적(하수인, 스폰, 뱀파이어 모두). 없으면 숨긴다. 시신을 호버하면 시신 패널(3-3).
3. 구성 (위에서 아래로):
   - 머리 줄: 이름 `h.2` + 역할 `small` 진영 색 ("아군" / "하수인" / "보스" / "스폰"). 스폰 이름은 "{원래 병종} · 스폰".
   - 큰 줄: 체력 "{hp}/{max}", 이동 "{mov}" — `num.1`, 아이콘 24px.
   - 작은 줄: 공격 "{atk}" (뱀파이어·스폰 추가 피해가 있으면 "{atk}+{bane}"), 방어, 사거리 — `num.2`, 아이콘 24px.
   - 경고 줄 하나 (`small` Bold). 여러 개면 위 것 하나만: ① 보름달 표적 `enemy` "보름달 표적 · 다음 적 턴에 흡혈당한다" (지금 위치가 안전하면 뒤에 " · 지금은 안전" `text.2`) ② 빛 속 `light` "빛 속 · 표적이 되지 않는다" ③ 방금 일어남 `spawn` "방금 일어남 · 이번 적 페이즈에 행동하지 않는다" ④ 관 속 뱀파이어 `light` "관 속 · 달 {MoonWake}에 깨어난다".
   - 기술 줄 (아군이고 기술이 있을 때): "기술: {이름들}" `small` `text.2`.
4. 아군 패널 체력이 최대의 1/3 이하면 체력 숫자를 `enemy`.
5. 패널은 설명 문장(병종 설명, 규칙 설명)을 넣지 않는다. 설명은 패널에 호버 0.5초 뒤 뜨는 툴팁(`frame.tip`, 폭 320)으로: 병종 설명 또는 지금 데모의 유닛 노트.

### 3-3. 시신 패널

1. 오른쪽 아래 `frame.spawn`. 머리 줄 "{이름}의 시신" `h.2` + "시신" `small` `spawn`.
2. 큰 줄: 일어날 스폰의 체력·이동, 작은 줄: 공격, 방어 0, 사거리 1 (units.md "원본의 공격력과 체력을 계승").
3. 경고 줄 `spawn`: "다음 적 페이즈 시작에 스폰으로 일어난다".

### 3-4. 행동 줄

1. 아군을 선택했고 그 아군이 이번 턴 행동하지 않았을 때만 보인다.
2. 슬롯 (왼쪽부터, 단축키 숫자):

| 키 | 슬롯 | 아이콘 | 누르면 |
|---|---|---|---|
| 1 | 아군 처치 | `Status_Dead_01` `enemy` | 처치 모드 켜기. 켜져 있으면 슬롯이 선택됨 상태, 이름이 "처치 취소", 다시 누르면 끈다 |
| 2 | 대기 | `Status_Defense_01` `ally` | 이 아군의 행동을 끝낸다 |
| 3 | 치료 (치료 기술이 있는 아군만, #99) | `Status_Health_01` `ally` | 치료 모드 켜기. 켜져 있으면 슬롯이 선택됨 상태, 이름이 "치료 취소", 다시 누르면 끈다. 처치 모드와 함께 켜지지 않는다(하나를 켜면 다른 하나는 꺼진다) |

3. 이동·공격은 슬롯이 아니라 보드 칸을 눌러서 한다 (지금 동작).
   - **수습(#99)** 도 보드 칸을 눌러서 한다: 수습 기술이 있는 아군을 고른 채 거리 1 의 시신 칸을 누르면 수습한다(공격과 같은 방식, 확인 없음). 그 아군을 고른 동안 수습할 수 있는 시신 칸은 `spawn` 점선 (처치 칸과 같은 모양, 색만 다름). 수습할 수 없는 시신 칸을 누르면 지금처럼 시신 패널을 보인다.
   - **치료(#99):** 치료 모드에서 치료할 수 있는 아군 칸(거리 2 이내, 자기 자신 아님, 체력이 최대보다 적음)은 `ally` 점선. 그 칸을 누르면 치료하고 모드가 꺼진다. 다른 칸을 누르면 치료하지 않고 모드만 꺼진다(처치 모드와 같다).
   - 치료할 수 있는 아군을 호버하면 그 아군 패널의 체력 줄에 "+{회복량}" 을 `ally` 로 덧붙인다(피해 미리 보기와 같은 계산 도움, ui.md).
4. 슬롯 오른쪽 아래에 단축키 칸 (ui-style.md 6).
5. 처치 모드에서 처치할 수 있는 아군 칸은 `enemy` 점선 (8-2).

### 3-5. 전투 기록

1. 접힌 상태: 머리 `small` `text.3` "전투 기록 ▾" + 최근 3줄. 최신이 위.
2. 줄은 `body` `text.2`, 한 줄로 쓰고 넘치면 말줄임(…). 줄 앞에 16px 아이콘 하나로 종류를 보인다: 처치·피해 `Status_Dead_01` `enemy`, 스폰·시신 `Status_Vampiric_01` `spawn`, 보름달·흡혈 `Status_Targeted_01` `moon.blood`, 턴 구분 줄은 아이콘 없이 `text.3`.
3. 머리를 누르면 펼침: 320×400 `frame.tip`, 이번 전투 전체 기록을 스크롤, 줄은 줄바꿈해서 다 보인다. 다시 누르거나 Esc 로 접는다.

### 3-6. 턴 종료

1. `btn.primary` "턴 종료" 200×56, 단축키 Space.
2. 행동하지 않은 아군이 있으면 왼쪽 위 배지에 그 수.
3. 버튼 위 `small` `text.2` 페이즈 이름 "아군 페이즈".
4. 행동하지 않은 아군이 있어도 확인 없이 바로 넘긴다 (지금 동작).

### 3-7. 보드 위 표시

ui-style.md 8 을 그대로 따른다. 덧붙여:
1. 보름달 표적 선(뱀파이어 → 표적): `moon.blood` 2px 점선. 글자 없음 (8-1 의 6).
2. 흡혈 범위 칸: 다음 적 턴이 보름달일 때만 (8-2).
3. 피해 미리 보기는 선택한 아군이 공격할 수 있는 적을 호버했을 때만 (8-3).
4. Alt 를 누르는 동안 적 이동력 (8-4). 사거리가 2 이상인 적(스켈레톤 궁수, #99)은 이동력 숫자 옆에 사거리 숫자를 같은 크기로 사거리 아이콘(유닛 패널의 것)과 함께 보인다. 위협 범위 칸은 칠하지 않는다(ui.md).

## 4. 적 턴

1. 턴이 바뀌면 보드 위 가운데 위에 배너 `h.1` "{n}턴 적 페이즈" (`enemy`) / "{n}턴 아군 페이즈" (`ally`), 1.3초 (지금 동작). 배너는 바탕 없이 글자에 `bg.night` 외곽선 2px.
2. 적 턴 동안: 턴 종료 버튼은 비활성 "적 행동 중…", 위 글자 "적 페이즈". 행동 줄·아군 패널은 숨긴다. 호버로 적 패널은 볼 수 있다.
3. 보름달 턴(적 턴 중 보름달)에는 게이지와 비네트가 ui-style.md 7-2 "보름달 턴" 상태.
4. 나가기는 적 턴 동안 비활성.

## 5. 결과

1. 보드 위에 화면 전체 `bg.night` 70% 를 깔고 가운데 `frame.popup` 520×자동. 승리는 틀 `ally`, 패배는 틀 `enemy`.
2. 구성: 제목 `display` "승리" (`moon`) / "패배" (`enemy`), 한 줄 설명 `body` `text.2`, 집계 넷(전사, 직접 처치한 아군, 스폰 발생, 흡혈 당함)을 `body` 이름 + `num.2` 숫자로, 캠페인이면 보상 줄(클리어 보상, 추가 목표, 획득 금화 `light`)과 해금 안내 `small` `text.2`.
3. 버튼: 캠페인이면 `btn.primary` "캠페인으로", `btn.normal` "같은 편성으로 다시", `btn.normal` "편성부터 다시". 데모면 "같은 편성으로 다시"가 `btn.primary`.
4. 바깥을 누르면 창이 닫히고 보드를 볼 수 있다. 그때 턴 종료 자리 버튼이 "결과 보기" 가 된다 (지금 동작).
5. 내용(문장·숫자)은 지금 결과 창과 같다.

| 1, 2, 3 | 행동 줄 슬롯 (3 은 치료가 있는 아군만) |
| Space | 턴 종료 / 배치 중에는 전투 개시 |
| Alt (누르는 동안) | 적 이동력 보기 |
| ? 버튼 | 규칙 요약 창 (`frame.popup` 720×자동, 제목 `h.1`, 규칙 줄 `body` `text.2`, 아래 `btn.ghost` "닫기") |
| 나가기 | 아군 턴이면 한 번 더 누르라는 확인 (버튼 글자 "전투를 포기할까요?", 2.5초), 배치 중이면 바로 나감 (지금 동작) |

## 정한 세부 (docs/design 에 없는 것)

- **배치 단계 배치: 편성 왼쪽, 작전 개요·유닛 패널 오른쪽.** 근거: 편성은 배치 내내 쓰는 1단계, 개요는 한 번 읽는 2단계. 아군 패널이 왼쪽인 아군 턴과 같은 쪽에 아군 정보를 둔다.
- **배치 중 보름달 게이지는 2단계.** 근거: 배치 중에는 바뀌지 않는다. 1단계 5개 제한 안에 편성·유닛 패널·전투 개시를 둔다.
- **경고 줄은 하나만.** 근거: 패널 높이 190 안에서 1단계 숫자를 가리지 않는다. 보름달 표적이 가장 급하다(vampire.md 의 유일한 예고).
- **설명 문장은 툴팁으로.** 근거: ui.md "정보는 최대한 깔끔하게". 지금 데모 카드의 긴 설명은 매 턴 필요하지 않다.
- **전투 기록 아이콘 세 종류.** 근거: 2단계는 글자를 `text.2` 로 낮추되, 처치·변이·보름달은 한눈에 갈려야 한다(combat.md "변이 이후 대처").
- **단축키 1·2·Space·Esc·Alt.** 근거: ui.md 키보드·마우스. 행동이 둘뿐이라 숫자 두 개로 충분하다.
- **턴 종료 확인 없음.** 근거: 지금 동작을 유지한다. 한 판 10~20분 동안 매 턴 누르는 버튼이라 확인은 템포를 끊는다. 배지가 남은 아군 수를 알려 준다.
