## 1. 화면 배치

기준 1920×1080, 안전 여백 24px (ui-style.md 1).

```
┌──────────────────────────────────────────────────────────────────────┐
│ 캠페인                                       금화 120  [진행 초기화] [메인 메뉴] │
│ 토벌 원정                                                              │
│ ┌───────────┐ ┌──────────────────────┐ ┌───────────────────────────┐ │
│ │ 원정 길     │ │ 장 정보                │ │ 병영 (upgrade.md)          │ │
│ │ ● 1장 ...  │ │ 3장 · 무너진 예배당      │ │                           │ │
│ │ │          │ │ 브리핑                  │ │                           │ │
│ │ ● 2장 ...  │ │ 목표·추가 목표·보상       │ │                           │ │
│ │ │          │ │ 자원·출전 병종·적         │ │                           │ │
│ │ ◎ 3장 ...  │ │                        │ │                           │ │
│ │ ...        │ │            [출정]       │ │                           │ │
│ └───────────┘ └──────────────────────┘ └───────────────────────────┘ │
└──────────────────────────────────────────────────────────────────────┘
```

| 자리 | 요소 | 크기 | 단계 |
|---|---|---|---|
| 위 왼쪽 | 머리: 위 `small` `text.2` "캠페인", 아래 `h.1` "토벌 원정" | 높이 96 | 2 |
| 위 오른쪽 | 금화: `num.1` `light` 숫자 + `small` `text.2` "금화". 그 오른쪽 `btn.ghost` "진행 초기화", `btn.normal` "메인 메뉴" | 높이 96 | 1 (금화), 3 (버튼) |
| 왼쪽 | 원정 길 (2절) `frame.menu` | 폭 420, 머리 아래 끝까지 | 1 |
| 가운데 | 장 정보 (3절) `frame.menu` | 폭 640 | 1 |
| 오른쪽 | 병영 (docs/ui/upgrade.md). 남은 폭 | 약 760 | 2 |

- 칸 사이 간격 16px. 세 칸은 위끝을 맞춘다.
- 바탕: `bg.night` 위에 **고른 장**의 보드 아트를 흐리게(블러 + 어둡게 60%) 깐다 (ui-style.md 11). 고른 장이 바뀌면 0.3초에 걸쳐 바뀐다.
- `frame.menu` 장식 `Crest` 는 마지막 장(백작의 성)을 골랐을 때만 장 정보 칸 위 가운데에 하나 둔다 (`Crests/` 의 `Crest_DarkFantasyMenus_Large_01`, `enemy`). 이 문장은 악마 해골이라 다른 장에는 두지 않는다 (ui-style.md 5-3). 원정 길·병영 칸은 장식 없이.

## 2. 원정 길

1. 칸 머리 `h.2` "원정 길", 그 아래 `small` `text.2` 한 줄 소개 (지금 `camp.intro`).
2. 장마다 한 줄 (높이 72). 위에서 아래로 1장 → 10장. 넘치면 칸 안에서 스크롤하고, 처음 열 때 고른 장이 보이게 스크롤한다.
3. 줄 왼쪽에 길 마디 원 28px, 마디끼리 세로선 2px 로 잇는다.

| 상태 | 마디 | 세로선(이 장 아래로) | 글자 |
|---|---|---|---|
| 클리어 | `ally` 채운 원 + 안에 체크 | `ally` | 장 번호 `small` `text.2`, 이름 `body` `text.1`, 오른쪽 `small` `ally` "클리어" |
| 열림 (클리어 전) | `moon` 테두리 원, 1.2초 주기 밝기 ±10% 맥박 | `line` | 이름 `body` Bold `text.1`, 오른쪽 `small` `moon` "열림" |
| 잠김 | `line` 테두리 원 | `line` | 이름 `body` `text.3`, 오른쪽 `small` `text.3` "잠김" |

4. 추가 목표를 받았으면 이름 오른쪽에 16px 별 표시(`light`). 못 받았으면 `line` 빈 별.
5. 마지막 장(백작의 성)의 마디·이름은 상태와 상관없이 `enemy` 색을 쓴다 (ui-style.md 11 의 3). 잠김이면 `enemy.dim`.
6. 줄을 누르면 그 장을 고른다 (잠긴 장도 고를 수 있다). 고른 줄은 바탕 `bg.panelDeep` + 왼쪽 3px 막대(`ally`, 마지막 장은 `enemy`).
7. 키보드: ↑/↓ 로 고른 장을 옮긴다.
8. 처음 고른 장: 열렸지만 아직 클리어하지 않은 장 중 첫 장. 모두 클리어했으면 마지막 장. 화면을 떠났다 돌아오면 마지막에 고른 장(전투에서 돌아온 경우 그 장).

## 3. 장 정보

위에서 아래로:

1. 장 번호 `small` `text.2` ("3장"), 장 이름 `h.1` (마지막 장은 `enemy`).
2. 브리핑 `body` `text.2` (지금 `Brief`). 최대 3줄.
3. 구분선 `Component_DarkFantasyMenus_Section_Break_02` (ui-style.md 11 의 5).
4. 목표 표 (`body`, 이름은 `text.2` 폭 120, 값은 `text.1`):

| 이름 | 값 |
|---|---|
| 목표 | "{보스 이름} 처치" |
| 추가 목표 | 추가 목표 문장. 받았으면 뒤에 `light` "· 받음" |
| 보상 | "클리어 {n} 금화 · 추가 목표 {n} 금화". 이미 받은 쪽은 `text.3` 로 쓰고 뒤에 "(받음)" (campaign.md 재도전) |
| 자원 | "인구 {n}", 은이 있으면 " · 은 {n}" (`light`) |
| 적 | 지금 `battle.enemyList` 문장 ("스켈레톤 {n}, {보스}") |

5. 출전 병종: `small` `text.2` "출전 병종" 아래에 병종 칩을 가로로. 칩 = 병종 무기 아이콘 24px + 이름 `small`, `frame.tip` 바탕. 이 장에서 처음 해금되는 병종은 칩 테두리 `light` + 이름 앞 "새 " (지금 `camp.new`).
6. 아래 오른쪽 출정 버튼 240×56:
   - 열림 (클리어 전): `btn.primary` "출정". 단축키 Enter.
   - 클리어: `btn.normal` "다시 출정". 단축키 Enter. 위에 `small` `text.3` "보상은 이미 받은 것을 빼고 받습니다" (보상을 모두 받았으면 "보상을 모두 받았습니다").
   - 잠김: 버튼 대신 `small` `text.3` "{앞 장 이름}을(를) 클리어하면 열린다".
7. 출정하면 그 장의 배치 화면으로 간다 (docs/ui/battle-hud.md 2절). 지금처럼 확인 없이 바로.

## 6. 지금 화면에서 바뀌는 것

1. 장 카드 열 개를 세로로 늘어놓던 왼쪽 칸 → 원정 길(짧은 줄) + 장 정보(고른 장 하나) 두 칸.
2. 장 카드마다 있던 "출정" 버튼 → 장 정보 칸의 버튼 하나.
3. 머리의 "장 선택" 제목·소개 카드 → 원정 길 칸 머리로.
4. 강화(병영) 칸은 docs/ui/upgrade.md 를 따른다. 자리만 오른쪽 세 번째 칸으로.

## 정한 세부 (docs/design 에 없는 것)

- **목록 + 상세 두 칸.** 근거: ui.md "정보는 최대한 깔끔하게". 열 장의 브리핑·보상·병종을 한꺼번에 펼치면 고를 때 필요 없는 글이 대부분이다. 길은 진행만, 상세는 고른 장만 보인다.
- **원정 길을 세로 마디로 그린다.** 근거: campaign.md "백작의 성까지 쳐들어가는 토벌 원정", "선택지는 두지 않는다". 한 줄 길이 그 흐름을 보여 준다. 갈래길(campaign.md "둘 수 있다")이 생기면 이 문서에 갈래 그리기를 더한다.
- **잠긴 장도 고를 수 있다.** 근거: 앞으로 무엇이 오는지(병종 해금, 마지막 성)를 미리 보며 강화를 계획할 수 있다. 출정만 막는다.
- **이미 받은 보상은 흐리게 + "(받음)".** 근거: campaign.md "이미 받았다면 다시 주지 않는다" 를 출정 전에 알 수 있게.
- **추가 목표 별 표시.** 근거: 클리어 여부와 추가 목표 여부를 길에서 한눈에. 금화·장식 없이 작은 표시 하나.
- **단축키 ↑/↓·Enter·Esc.** 근거: ui.md 키보드·마우스.
