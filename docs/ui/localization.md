# 다중 언어

> 출처: docs/design/ui.md, docs/design/campaign.md, docs/design/overview.md (커밋 f7fc7f8)
> 언어 방향은 docs/design 에 없다. 사용자 결정(2026-11-06, 이슈 #23, docs/dev/localization-plan.md 5절)을 이 기획서의 "정한 세부" 로 쓴다.
> 목적: 지원 언어, 처음 언어, 언어 고르는 곳, 언어를 바꾸면 바뀌는 것, 글자 배지, 언어별 글꼴, 영어 문체·용어, 영어가 길 때의 규칙을 정한다. 표·메시지 구조는 docs/dev/localization-plan.md 3절.

## 요구사항

### 지원 언어

1. 처음 지원 언어는 둘이다.

| 순서 | 언어 | Locale | 언어 줄에 보일 이름 | 역할 |
|---|---|---|---|---|
| 1 | 한국어 | `ko` | 한국어 | 기준 언어. 모든 문장의 원문 |
| 2 | 영어 | `en` | English | 번역 |

2. 언어 이름은 지금 언어와 상관없이 그 언어로 쓴다("한국어", "English"). 이름은 Locale 의 이름 칸(Locale Name)에 둔다.
3. 언어 목록·순서·이름·글꼴은 Locale 과 문자열 표에서만 정한다. 코드에 언어를 박지 않는다. 언어를 더하는 일은 Locale 하나, 표의 언어 열 하나(문장, 배지, 글꼴), 위 표 한 줄이다.
4. 한 언어의 칸이 비면 한국어 문장을 보인다. 빈 글이나 키 이름을 보이지 않는다. 내보내는 빌드는 영어 빈칸이 0 이어야 한다(계획 L6).

### 처음 켰을 때 언어

5. 다음 순서로 정한다.
   1. 저장한 언어(플레이어가 언어 줄에서 고른 것). 저장한 언어가 지원 목록에 없으면 없는 것으로 본다.
   2. OS 언어가 지원 언어이면 그 언어. 지역은 보지 않는다(en-US, en-GB → English, ko-KR → 한국어).
   3. 둘 다 아니면 한국어.

### 언어 고르는 곳

6. 메인 메뉴 오른쪽 위에 **언어 줄** 하나를 둔다. 설정 창(docs/ui/settings.md)은 그 왼쪽 "설정" 글로 열고, 언어는 설정 창으로 옮기지 않는다.
7. 언어 줄 모양.
   - 지원 언어마다 작은 버튼 하나. 순서는 1번 표 순서. 버튼 글은 언어 이름(2번).
   - 지금 언어와 나머지의 모양은 docs/ui/main-menu.md 12 (달과 피 스타일)를 따른다.
   - 자리: 화면 오른쪽 위 모서리, 안전 여백 24 안 (docs/ui/main-menu.md 12). 가운데 메뉴 본문과 겹치지 않는다.
   - "언어" 같은 이름표나 그림은 두지 않는다.
8. 동작.
   - 다른 언어 버튼을 누르면 확인 없이 바로 바뀐다. 게임을 다시 시작하지 않는다. 메인 메뉴가 새 언어·새 글꼴로 다시 그려진다.
   - 새 언어 표가 실리는 동안은 이전 언어 화면을 그대로 두고, 실리면 다시 그린다. 그 사이 빈 화면을 보이지 않는다.
   - 지금 언어 버튼을 누르면 아무 일도 없다.
   - 고른 언어는 바로 저장되고, 다음에 켜도 그 언어다(5번 1).
   - 언어 저장은 캠페인 진행과 따로다. 캠페인 화면의 "진행 초기화" 는 언어를 바꾸지 않는다.
9. 언어 줄은 메인 메뉴에만 있다. 캠페인 화면, 전투 화면, 결과 창에는 없다. **전투 중에는 언어를 바꿀 수 없다.** 바꾸려면 메인 메뉴로 돌아간다(데모 전투는 "나가기", 캠페인은 "메인 메뉴").
10. 키보드 단축키는 두지 않는다. 마우스로 누른다(ui.md 조작 환경).

### 언어를 바꾸면 바뀌는 것

11. 플레이어가 보는 모든 글이 새 언어로 바뀐다.

| 묶음 | 무엇 |
|---|---|
| 화면 고정 문장 | 메인 메뉴(소개, 선택 카드), 캠페인 화면(머리, 장 카드, 병영), 전투 화면(머리, 옆 칸, 아래 안내 줄, 규칙 요약, 유닛·시신 카드), 결과 창 |
| 게임 데이터 | 병종 이름·설명·글자 배지, 강화 이름·설명, 장 번호·제목·소개, 보스 이름, 스켈레톤 이름, 추가 목표 문장 |
| 전투 글 | 전투 기록, 안내, 거절 사유, 단계 띠, 보드 위에 떠오르는 글(흡혈, 처치, 흡혈 실패. 피해 수는 숫자라 같다), 보름달 표시 글 |
| 글꼴 | 화면 글꼴 둘(본문, 제목·배지). 18~21번 |

12. 바뀌지 않는 것.
    - 게임 제목 "PROJECT VAMPIRE SPAWN". 두 언어 같은 글이다(main-menu.md 1번).
    - 숫자. 두 언어 모두 아라비아 숫자, 자릿수 쉼표 없음(지금 한국어 화면과 같다).
    - 색, 배치, 글자 크기, 배지 칸 크기.
    - 캠페인 진행. 저장 데이터에는 문장이 없다.
    - 에디터 도구(게임 데이터 편집기, 도구 모음 창), 데이터 검사 문장, 인스펙터 툴팁, 개발 로그. 한국어만이고 번역하지 않는다.
13. 글은 그릴 때마다 지금 언어로 만든다. 전투 기록도 완성된 문장이 아니라 메시지로 남기므로, 언어가 바뀐 뒤 다시 그리면 이미 쓴 줄도 새 언어로 바뀐다. 지금은 전투 중에 바꿀 수 없어(9번) 플레이어에게는 보이지 않지만, 문장을 미리 만들어 쌓아 두지 않는다.

### 글자 배지

- **지금 화면에는 배지가 없다.** 달과 피 스타일(docs/art/ui-style.md 9)은 병종을 무기 아이콘으로 보인다(편성, 출전 병종 칩, 병영). 배지 글은 전투 상태 문자열(`Battle.Snapshot`)과 데이터 편집기가 읽으므로 표에 남긴다. 아래 14~16 은 그 표 칸의 규칙이다. 화면에 배지를 다시 쓰게 되면 이 줄을 지운다.

14. 배지는 병종을 한눈에 가르는 짧은 글이다. 칸 크기(34×34), 글자 크기, 색(등급 색)은 언어와 상관없이 같다. 배지 글만 언어별로 표의 칸에 둔다(`unit.<key>.glyph` 등, 계획 3절). 이름에서 자동으로 만들지 않는다.
15. 언어별 규칙.
    - 한국어: 한 글자(지금 그대로).
    - 영어: **대문자 두 글자.** 영어 이름이 두 낱말 이상이면 앞 두 낱말의 첫 글자, 한 낱말이면 앞 두 글자. 다른 배지와 겹치면 두 번째 글자를 그 낱말의 다음 자음으로 바꾼다.
    - 나중에 더하는 언어: 라틴 문자는 영어 규칙, 한 글자가 뜻을 담는 문자(한자, 가나)는 한 글자. 어느 언어도 두 글자를 넘지 않는다.
16. 배지 표. 병종·하수인 목록은 `Assets/_Project/Data/Units`, `Data/Enemies` 의 것이다.

| 대상 | 한국어 이름 | 한국어 배지 | 영어 이름 | 영어 배지 |
|---|---|---|---|---|
| 농민 창병 (`pspear`) | 농민 창병 | 창 | Peasant Spearman | PS |
| 농민 궁수 (`parcher`) | 농민 궁수 | 활 | Peasant Archer | PA |
| 검사 (`sword`) | 검사 | 검 | Swordsman | SW |
| 궁수 (`archer`) | 궁수 | 궁 | Archer | AR |
| 기사 (`knight`) | 기사 | 기 | Knight | KN |
| 사냥꾼 (`hunter`) | 사냥꾼 | 사 | Hunter | HU |
| 스켈레톤 | 스켈레톤 | 골 | Skeleton | SK |
| 뱀파이어(모든 장의 보스) | 장마다 다름 | 흡 | 장마다 다름 | VA |
| 스폰 | 스폰(원본 병종) | 원본 병종 배지 | 원본 병종 + Spawn (예: Knight Spawn) | 원본 병종 배지 (예: 기사의 스폰은 KN) |

17. 지금 화면에 배지가 보이는 곳은 편성 칸과 병영 카드(아군 병종)뿐이다. 스켈레톤·뱀파이어·스폰 배지는 데이터에만 있고, 화면에 나올 때 이 표를 쓴다. 뱀파이어 배지 "흡" 은 지금 규칙 코드(`Core/Battle.cs`)에 박혀 있으므로, 다른 배지처럼 표의 칸으로 옮긴다.

### 언어별 글꼴

18. 목록의 이름은 먼저 게임에 들인 글꼴(`Resources/Fonts/{이름}`)에서, 없으면 OS 에 깔린 글꼴에서 찾는다. 찾은 첫 글꼴로 그리고, 그 글꼴에 없는 글자는 찾은 나머지 글꼴로 차례로 그린다(#118, 2026-11-13 사용자가 Hahmlet·Source Han Serif K 를 들임).
19. 언어마다 목록 둘을 둔다: 본문(`font.body`), 제목·배지(`font.display`). 목록은 표의 그 칸에 글꼴 이름을 쉼표로 이어 둔다(계획 3절).

| 언어 | 본문 `font.body` | 제목·배지 `font.display` |
|---|---|---|
| 한국어 | Hahmlet-Medium, SourceHanSerifK-VF, Malgun Gothic, Apple SD Gothic Neo | Hahmlet-Bold, SourceHanSerifK-VF, Malgun Gothic, AppleMyungjo |
| 영어 | Hahmlet-Medium, SourceHanSerifK-VF, Segoe UI, Arial | Hahmlet-Bold, SourceHanSerifK-VF, Georgia, Times New Roman |

20. 모든 언어 목록의 끝에는 다른 지원 언어의 글자를 그릴 수 있는 글꼴을 둔다. 영어 목록 끝의 한국어 글꼴은 영어 화면에서도 보이는 언어 줄의 "한국어" 버튼과, 아직 번역되지 않아 한국어로 보이는 칸(4번)을 그린다.
21. 언어를 바꾸면 화면 글꼴도 그 언어 목록으로 바뀐다. 보드 위 3D 글(떠오르는 글, 보름달 표시)은 지금 쓰는 엔진 기본 글꼴을 두 언어 모두 그대로 쓴다.

### 영어 문체

22. 어조.
    - 어둡고 건조한 다크 판타지(campaign.md "이야기"). 농담, 과장, 현대 속어를 쓰지 않는다. thee·thou 같은 옛말도 쓰지 않는다.
    - 한국어보다 길게 풀지 않는다. 설명을 덧붙이지 않는다.
    - 플레이어에게 하는 말(안내, 버튼 설명, 규칙)은 2인칭 명령형·현재형: "Click an ally to give orders."
    - 전투 기록·단계 띠는 3인칭 현재형 짧은 문장: "Knight falls." 끝은 마침표, 한국어가 "!" 인 줄만 "!".
    - 기록에 끼워 넣는 이름 앞에는 관사를 붙이지 않는다(이름을 고유 명사처럼 쓴다). 보스 이름 칸도 "The" 없이 쓴다.
23. 표기.
    - 대문자: 버튼, 화면·카드 제목은 Title Case("End Turn"). 문장·설명·기록은 Sentence case. 병종·보스·장 제목·강화 이름은 늘 대문자로 시작한다. 일반 용어(spawn, corpse, full moon, light)는 문장 안에서 소문자.
    - 복수: 수를 끼우는 문장은 Smart String 복수형으로 단수·복수를 맞춘다("1 ally", "2 allies").
    - 기호: "·" 구분은 그대로 쓴다. 「」는 큰따옴표(" ")로 바꾼다. ✓ ○ 는 그대로.
    - 한국어 UI 의 합쇼체와 전투 기록의 해라체 차이는 위 22번의 명령형·현재형 구분으로 대신한다.
24. 용어 표. 기계 초안과 사람 검토 모두 이 표를 따른다. 새 핵심 용어가 생기면 이 표에 먼저 더한다. 병종 이름은 16번 표.

| 한국어 | 영어 | 쓰는 법 |
|---|---|---|
| 뱀파이어 | vampire | 보스 이름 안에서는 대문자(Vampire Count) |
| 백작 | Count | 뱀파이어 백작 = Vampire Count |
| 스폰 | spawn | 단수·복수 같은 꼴. 이름은 "<병종> Spawn"(Knight Spawn) |
| 변이, 스폰으로 일어나다 | rise (as spawn) | turn 은 쓰지 않는다(턴과 겹친다). 변이 대기 = Rising, 스폰 발생 = Risen |

### 영어가 길 때

25. 여러 줄 글(설명, 안내, 전투 기록, 규칙 요약, 결과 창 문장, 작전 개요의 이름 칸)은 줄바꿈한다(지금 그대로). 길어진 카드는 전투 옆 칸과 캠페인 두 칸에서 스크롤된다. 메인 메뉴와 결과 창은 스크롤이 없으므로 영어로도 참조 해상도 화면(1600×900) 안에 들어와야 한다.
26. 한 줄 글(버튼, 칩, 카드 제목, 결과 창 오른쪽 값)은 줄바꿈하지 않는다. 버튼·칩은 화면 기획서의 고정 크기다 (ui-style.md 15-2 의 6, #43). 글이 버튼·칩·카드 밖으로 나가면 번역을 줄인다.
27. 너비가 정해진 자리는 영어 글자 수(공백 포함)를 넘지 않게 쓴다. 넘으면 약어(24번)나 짧은 낱말로 줄인다.

| 자리 | 영어 상한 |
|---|---|
| 전투 머리 통계 이름표(인구, 달, 턴, 변이 대기 등. 칸 너비 52) | 14자 |
| 유닛 카드 능력치 칸 이름 | 24번 약어만 |
| 글자 배지 | 2자(15번) |

28. 넘친다고 글자 크기를 자동으로 줄이지 않는다(Best Fit 쓰지 않음). 줄임표(…)로 자르지 않는다. 고치는 것은 번역이다.
29. 확인: 가짜 번역(글을 늘린 표)과 영어 표로 메인 메뉴, 캠페인, 배치, 전투, 결과 창 스크린샷을 찍어 잘리거나 겹친 글이 없어야 한다(계획 L6).

## 정한 세부 (docs/design 에 없는 것)

- **언어 줄은 메인 메뉴에만 둔다(6, 9번).** 근거: 설정 화면이 없다. 언어는 한 번 정하면 거의 바꾸지 않는다. 메뉴는 켜면 처음 보는 화면이라, OS 언어로 잘못 정해져도 바로 고칠 수 있다. 전투 중 바꾸기를 빼면 전투 화면을 고칠 일이 없다.
- **순환 버튼 하나 대신 언어마다 버튼을 둔다(7번).** 근거: 누르기 전에 무엇으로 바뀌는지 보인다. 언어 이름을 그 언어로 쓰면 지금 언어를 못 읽는 사람도 자기 언어를 찾는다.
- **확인 없이 바로 바뀐다(8번).** 근거: 되돌리기가 한 번 누르기다. 두 번 누르기 확인은 되돌릴 수 없는 일(진행 초기화, 강화 구매, 전투 포기)에만 쓴다.
- **영어 배지는 영어 이름의 머리글자 대문자 두 글자(15번).** 근거: 한 글자면 겹친다(농민 둘이 P, 검사·스켈레톤이 S). 한국어처럼 무기 이름을 쓰면 창의 SP 가 Spawn 과 헷갈린다. 이름 머리글자는 새 병종에도 같은 규칙으로 정해지고, 농민 병종은 P 로 시작해 등급도 드러난다.
- **변이는 rise, 아군 처치는 mercy kill(24번).** 근거: turn 은 게임의 턴과 겹친다. 아군 처치는 적을 쓰러뜨리는 defeat 와 구별해야 하고, 메뉴 소개의 "살릴 수 없는 아군은 직접 보내세요" 의 무게를 담는다.
- **영어 글꼴 목록 끝에 한국어 글꼴(20번).** 근거: 영어 화면에서도 언어 줄의 "한국어" 버튼이 보인다.
- **넘치면 번역을 줄이고 글자 크기는 줄이지 않는다(28번).** 근거: ui.md "정보 밀도" — 같은 급의 글이 같은 크기여야 중요도 차등이 보인다.

## 열린 질문 (사용자가 정할 것)

1. 게임의 정식 제목과 영어판 제목(main-menu.md 열린 질문 1). 지금은 두 언어 모두 "PROJECT VAMPIRE SPAWN".
2. OS 언어가 지원하지 않는 언어(예: 일본어)일 때 한국어 대신 영어로 시작할지. 지금은 사용자 결정대로 한국어(5번 3).
3. 나중에 설정 화면(소리, 화면 등)을 만들면 언어 줄을 그리로 옮길지, 메뉴에도 남길지.
4. 기계 초안을 검토할 사람(사용자, 외부 번역가).
