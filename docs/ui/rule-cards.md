> 스타일: docs/art/ui-style.md (16-2 "특정한 순간", 14-1 글 예산). 함께 보는 기획서: docs/ui/battle-hud.md (규칙 요약 창 6-1), docs/content/stages.md (장마다 새것), docs/ui/unit-detail.md (용어 칩)
> 레퍼런스: Into the Breach 의 "UI 로 설명 못 하는 기믹은 뺀다", 한 줄 툴팁 (#150 보고서 B2)
> 목적: 장의 배치 단계가 시작될 때 그 장에서 처음 만나는 것을 카드 한 장씩으로 알린다. 튜토리얼이 따로 없는 게임의 온보딩이다.

## 요구사항

### 1. 언제

1. 캠페인 전투의 배치 단계가 시작될 때 뜬다. 데모 전투, "같은 편성으로 다시"(바로 시작)에는 뜨지 않는다.
2. 그 장의 카드 가운데 **아직 본 적 없는 것만** 뜬다. 하나도 없으면 아무것도 뜨지 않는다.
3. 본 카드 id 는 캠페인 저장(`seen`)에 남는다. 그래서 재도전·다른 장에서 같은 것이 다시 뜨지 않는다. 진행 초기화는 이 기록도 지운다.
4. 카드를 넘길 때마다 그 카드를 본 것으로 저장한다. 중간에 나가면 남은 카드는 다음에 뜬다.

### 2. 카드가 되는 것 (`Campaign.NewRules`)

손 목록은 1장 셋뿐이고 나머지는 데이터에서 계산한다.

| 장 | 카드 | id |
|---|---|---|
| 1장 | 변이, 빛, 달 (이 순서) | `rule:turn`, `rule:light`, `rule:moon` |
| 2장부터 | ① 그 장에서 해금되는 병종 (`UnitType.UnlockAt` = 장 번호) | `unit:<병종>` |
| | ② 앞 장들에 없던 적 종류 (장 적 목록, 놓인 시신·스폰·뱀파이어 뺌) | `foe:<종류>` |
| | ③ 앞 장들에 없던 목표 종류 (방어전·호위) | `goal:defense`, `goal:escort` |

- 지금 데이터로는 2장 방어전, 3장 검사, 4장 궁수·해골 대장·스켈레톤 궁수, 5장 장의사·구울, 6장 정찰병·호위, 7장 성녀·스켈레톤 중갑병·가고일, 8장 기사, 9장 연금술사, 11장 검은 기사. 10장과 12~20장은 카드가 없다.

### 3. 창

1. 화면 가운데 고정 크기 창 (전투 HUD 좌표 640×496, 전투 HUD 크기 설정을 따른다). 틀 `frame.popup` (`ally`), 뒤는 규칙 요약 창과 같은 어두운 막.
2. 안: 오른쪽 위 "n/전체" (`small` `text.3`, 한 장이면 없음) · 가운데 큰 아이콘 128 · 이름 `h.1` `text.1` · 한 문장 `body` `text.2`, 네 줄까지(영어) · 아래 가운데 버튼 "다음"(`card.next`), 마지막 장은 "닫기"(`hud.close`), 안쪽 단축키 칸 "Space".
3. 아이콘과 색: 규칙은 규칙 요약 창의 그 용어(battle-hud.md 6-1), 병종은 무기 아이콘 `ally`, 적은 하수인 겉모습 아이콘 `enemy`, 목표는 `Map_Flag_01` `ally`.
4. 문장: 규칙은 규칙 요약 창의 용어 설명 그대로. 병종·적·목표는 `card.unit.<병종>`, `card.foe.<종류>`, `card.goal.<목표>` (이름은 `card.goal.<목표>.name`). 있는 글(병종 소개, 적 노트)을 한 문장으로 줄였다.

### 4. 조작

| 입력 | 동작 |
|---|---|
| 창·막 아무 곳 클릭, Space, Enter | 다음 카드, 마지막이면 닫기 |
| Esc | 남은 카드를 모두 본 것으로 하고 닫기 |

- 카드가 떠 있는 동안 보드 클릭, 숫자 키, Space(전투 개시), I(상세 창)는 받지 않는다.

### 5. 검사

- `tools/ui-audit/sweep.sh` 의 `2z-cards` 단계가 문장이 가장 긴 카드를 띄워 6개 화면비를 보고, `3-deploy` 단계가 카드를 닫는다 (docs/dev/ui-audit.md).
- EditMode `RuleCardTests`: 1장 셋, 뒤 장의 계산, 모든 카드 문장, 본 카드 저장, 옛 저장(`seen` 없음)이 그대로 읽힘.

## 정한 세부 (docs/design 에 없는 것)

- **1장은 규칙 셋만.** 근거: 1장의 병종(농민 둘)과 적(뱀파이어·스켈레톤)은 배치 화면과 규칙 셋이 이미 말한다. #150 보고서 B2 "1장에서 변이·빛·보름달".
- **id 단위로 한 번.** 근거: 같은 적이 뒤 장에 다시 나와도 새것이 아니다 (stages.md "한 장에 새것 하나").
- **옛 저장에는 기록이 없어 카드가 다시 뜬다.** 근거: 진행·금화·강화는 그대로 읽히고, 카드를 한 번 더 보는 것은 해가 없다.
- **Esc 는 모두 닫기.** 근거: 다른 창과 같이 Esc 는 닫는 키다. 다시 보고 싶으면 규칙 요약 창이 있다.
