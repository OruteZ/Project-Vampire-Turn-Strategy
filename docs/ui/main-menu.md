# 메인 메뉴

> 출처: docs/design/overview.md, docs/design/ui.md (커밋 f7fc7f8)
> 목적: 게임을 켜면 처음 보는 화면이 무엇을 보여 주고 어디로 보내는지 정한다.

## 요구사항

### 머리

1. 맨 위에 게임 제목을 둔다. 제목은 가제 **"PROJECT VAMPIRE SPAWN"** 이다. 정식 제목이 정해지면 바꾼다(열린 질문 1).
2. "한 명이 물리면 전열이 무너진다" 는 화면에 쓰지 않는다. overview.md 는 이 문장을 게임을 설명하는 문장이라고 했다. 화면 문구가 아니다.
3. 제목 아래에 게임 소개 한 줄을 둔다.

   > 육각 타일 턴제 전술. 뱀파이어에게 쓰러진 병사는 스폰이 되어 아군을 공격합니다. 빛을 지키고, 살릴 수 없는 아군은 직접 보내세요.

4. "프로토타입" 같은 개발 단계 표시는 두지 않는다.

### 선택지

5. 큰 선택 카드 둘을 나란히 둔다. 마우스로 누른다(ui.md 조작 환경).

| 카드 | 제목 | 설명 | 아래 줄 | 누르면 |
|---|---|---|---|---|
| 데모 | 데모 전투 | 모든 유닛을 쓸 수 있는 단일 전투. 강화 없음. | 데모 장의 자원: "인구 {pop}" 에 은이 있으면 " · 은 {silver}" | 데모 장 배치 화면 |
| 캠페인 | 캠페인 | 농민군에서 사냥꾼까지. 장을 넘길 때마다 유닛이 해금되고, 금화로 유닛을 강화합니다. | "{클리어한 장}/{전체 장}장 클리어 · 금화 {금화}" | 캠페인 화면 |

6. 데모 카드의 자원 줄은 데이터(데모 장의 인구·은)에서 만든다. 데이터를 바꾸면 따라 바뀐다.

### 정보 차등 (ui.md "정보 밀도")

7. 화면의 중요도를 세 단계로 나눈다.
   - 제목: 가장 크게.
   - 선택 카드 제목: 그다음.
   - 소개 문장과 카드 설명: 흐린 색.
   - 카드 아래 줄(자원, 진행)은 강조색(촛불색)으로 작게.

## 정한 세부 (docs/design 에 없는 것)

- **제목 자리에 가제를 둔다(1번).** 근거: overview.md 가 정체성 문장을 화면에서 뺐다. 비는 자리에는 게임 이름이 오는 것이 보통이다. 정식 이름은 정해진 것이 없어 저장소 이름을 가제로 쓴다.
- **소개 문장은 남긴다(3번).** 근거: 화면 문구로 금지된 것은 정체성 문장 하나다. 소개 문장은 메뉴에서 게임을 알려 주는 역할을 한다.
- **"프로토타입" 표시를 뺀다(4번).** 근거: 개발 단계는 게임 화면 정보가 아니다.
