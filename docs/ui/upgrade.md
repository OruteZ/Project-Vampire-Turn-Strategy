## 요구사항

### 1. 자리·여는 법·닫는 법

1. 병영은 캠페인 화면의 세 번째 레이어(L3)다 (stage-select.md 1절). 장 선택과 같은 화면이고 바탕은 원정 지도다.
2. 여는 법: 왼쪽 아래 병영 버튼, 또는 B. 지도(L1)와 장 정보(L2) 어디서나 열린다.
3. 닫는 법: 칸의 닫기 버튼, Esc, B, 또는 병영 버튼을 한 번 더. 온 레이어(L1 또는 L2, 같은 장)로 돌아간다.
4. 칸: 오른쪽 위 한 점 앵커, (−24, −24), **560×680 고정**. 틀 `frame.menu` (`ally`), 장식 없음. 장 정보 칸과 같은 자리이고, 한 번에 하나만 열린다.
5. 카메라는 지도의 야영지를 본다 (campaign-map.md 7·9). 지역 표식은 숨긴다.
6. 가진 금화는 이 레이어에만 보인다 (stage-select.md 6절).

### 4. 병종 탭

1. 병종마다 탭 하나, 병종 순서대로(창병, 농민 궁수, 검사, 궁수, 기사, 사냥꾼). 늘 6개다.
2. 탭 = `frame.ally` 축소판 64×64 + 무기 아이콘 40px (ui-style.md 9).

| 탭 상태 | 모양 | 누르면 |
|---|---|---|
| 열림 (그 병종이 해금된 장을 클리어함) | 틀 `ally.dim`, 아이콘 `ally` | 그 병종을 고른다 |
| 고름 | 틀 `ally` + 바깥 2px 빛 | |
| 미해금 (그 병종이 아직 해금되지 않음) | 틀 `line`, 무기 아이콘 대신 자물쇠 28px `text.3`. 툴팁 `camp.lockedBy` (그 병종이 해금되는 장의 이름). 병종 이름·강화는 보이지 않는다 | 아무 일 없음 |
| 잠김 (해금됐지만 그 장을 아직 클리어하지 않음) | 틀 `line`, 아이콘 `text.3`, 오른쪽 아래 자물쇠 18px `text.3`. 툴팁 `camp.lockedBy` (그 병종이 해금되는 장의 이름) | 고른다. 강화 줄은 보이되 사는 버튼 대신 자물쇠 (5절 4번) |
| 살 수 있는 강화가 있음 | 위 상태에 더해 오른쪽 위 안쪽 지름 10 점 `light` | |

3. 툴팁: 병종 이름 (잠김은 위 문장).
4. ←/→ 로 탭을 옮긴다. 끝에서 멈춘다.
5. 열 때 고른 탭: 이번 실행에서 마지막에 고른 탭. 없으면 살 수 있는 강화가 있는 첫 탭, 그것도 없으면 첫 열린 탭, 그것도 없으면 첫 탭.

### 6. 사기

1. "강화" 를 누르면 그 버튼이 확인 상태가 된다. 2.5초 안에 한 번 더 누르면 산다.
2. 2.5초가 지나거나 다른 곳을 누르면 "강화" 로 돌아간다. 한 번에 한 버튼만 확인 상태다.
3. 사면 금화가 바로 줄고, 줄이 "보유" 가 되고, 능력치 줄이 새 값으로 바뀐다. 저장된다.
4. 산 줄의 테두리가 0.2초 번쩍이고 `light` 로 남는다. 머리 금화 숫자도 0.2초 번쩍인다 (ui-style.md 12). 탭의 점과 병영 버튼 배지 숫자가 새로 맞춰진다.
5. 강화 초기화 버튼은 두지 않는다 (progression.md "넣지 않을 것").

### 7. 진행 초기화

7. 진행 초기화는 지도 레이어(L1) 오른쪽 위에 있다 (stage-select.md 2-2). 병영에는 두지 않는다.

### 8. 문장

새 키는 stage-select.md 8절(`camp.barracksName`, `camp.affordable`, `camp.toMap`). 쓰는 키: `camp.barracksHelp`, `camp.noUpgrades`, `camp.gold`, `camp.upgrade`, `camp.buyConfirm`, `camp.owned`, `camp.inherit`, `camp.noInherit`, `camp.needGold`, `camp.lockedBy`, 강화 이름·효과(`upgrade.<id>.*`), 병종 이름(`unit.<key>.*`). `camp.barracks`("병영 · 유닛 강화")와 `camp.statLine`·`camp.cost` 는 이 화면에서 더 쓰지 않는다.

## 정한 세부 (docs/design 에 없는 것)

- **확인 방식은 두 번 누르기다(6번).** 근거: 진행 초기화와 전투 나가기가 이미 같은 방식이다. 시간은 나가기와 같은 2.5초다.
- **병종 탭 6개를 늘 둔다(4절).** 근거: 고정 크기 칸(ui-style.md 15)에서 탭 수가 진행에 따라 늘면 칸 모양이 바뀐다. 해금된 병종은 강화가 열리기 전에도 미리 보면 progression.md "빌드를 고민" 을 앞당긴다. 아직 해금되지 않은 병종은 자물쇠만 보인다(이름·강화 스포일러를 막는다. 방향성 검토 #43) (장 선택의 "잠긴 장도 고를 수 있다" 와 같은 생각). 지금까지는 열리지 않은 병종 카드를 숨겼다.
- **병종을 하나씩 본다(탭).** 근거: 병종 6 × 강화 2 를 한 칸에 펼치면 칸이 화면 높이를 넘는다. 강화는 병종 단위 결정이다 (progression.md "성장은 병종 단위").
- **카메라는 야영지.** 근거: 병영 레이어에도 가운데 게임 화면이 있어야 한다 (ui-style.md 16-1). 소녀전선 2 는 강화하는 무기를, Baldur's Gate 3 는 야영지를 3D 로 보인다.
- **가격·보유는 `light`.** 근거: ui-style.md 2-2 의 4 "`light` 는 광원·재화에만".
- **스폰 계승은 이름 앞 송곳니 + 툴팁.** 근거: ui-style.md 14-4.

## 후속 (이번 구현 밖)

- 고른 병종의 3D 모델을 야영지 모닥불 옆에 세운다 (`ArtCatalog.allyLooks` 의 모델, 대기 동작). 탭을 바꾸면 모델이 바뀐다. 소녀전선 2 강화 화면처럼 강화하는 대상이 가운데 보인다. 1차는 야영지 소품만 둔다. → 구현 #86: `CampaignMapView.ShowUnit`, 모닥불에서 야영지 기준 (1.2, −1.4), 카메라 쪽(남쪽)을 보고 등급 색 고리. 숨은 병종 탭은 모델 없음.
