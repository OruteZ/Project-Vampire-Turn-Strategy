# 강화 화면

> 출처: docs/design/progression.md, docs/design/ui.md (커밋 f7fc7f8)
> 스타일: docs/art/ui-style.md (커밋 bc8bc27). 함께 보는 기획서: docs/ui/stage-select.md (같은 화면, 칸 배치)
> 목적: 캠페인 화면 안의 병영(유닛 강화) 칸이 무엇을 보여 주고 어떻게 사게 하는지 정한다. 규칙은 docs/systems/progression.md.

## 요구사항

### 자리

1. 병영은 캠페인 화면 오른쪽 세 번째 칸이다 (docs/ui/stage-select.md 1절: 원정 길, 장 정보, 병영). 위에 금화가 늘 보인다(캠페인 화면 머리). 칸 틀은 `frame.menu`, 장식 없음, 폭은 남은 폭(약 760). 넘치면 칸 안에서 스크롤한다.

### 안내 카드

2. 맨 위 카드는 제목 "병영 · 유닛 강화" 와 안내 문장 하나를 보여 준다.

   > 강화는 같은 병종 전체에 적용되고, 한 번 사면 되돌릴 수 없습니다. 유닛이 해금된 장을 클리어한 뒤부터 그 유닛을 강화할 수 있습니다. 스폰이 되면 체력·공격·이동 강화만 물려받습니다.

3. 강화 초기화 버튼은 두지 않는다.

### 병종 카드

4. 강화가 열린 병종마다 카드 하나를 둔다. 순서는 병종 순서다.
5. 카드 머리에는 다음을 둔다.
   - 병종 글자 배지와 이름
   - 지금 능력치 한 줄: "체력 · 공격(+은탄) · 방어 · 이동 · 사거리". 산 강화가 반영된 값이다.
6. 열린 병종이 없으면 안내 한 줄을 둔다: "아직 강화할 수 있는 병종이 없습니다. 1장을 클리어하면 농민군 강화가 열립니다."

### 강화 칸

7. 병종 카드 안에 강화마다 칸 하나를 둔다. 각 칸에는 다음이 있다.
   - 이름
   - 가격("N 금화") 또는 "보유"
   - 효과 설명
   - 스폰 표시("스폰이 물려받음" / "스폰이 물려받지 않음"). 표시 규칙은 progression.md 15번이다.
8. 산 강화 칸은 테두리를 강조(`light`)하고 버튼을 두지 않는다.
9. 사지 않은 강화 칸에는 "강화" 버튼을 둔다. 금화가 모자라면 비활성이다.

### 사기 전 확인

10. "강화" 를 누르면 그 버튼이 "정말 살까요? N 금화" 로 바뀐다(위험 색). 2.5초 안에 한 번 더 누르면 산다.
11. 2.5초가 지나거나 다른 곳을 누르면 원래 "강화" 로 돌아간다. 한 번에 한 버튼만 확인 상태가 된다.
12. 사면 금화가 바로 줄고, 칸이 "보유" 로 바뀌고, 병종 카드의 능력치 줄이 새 값으로 바뀐다. 저장된다.

### 진행 초기화

13. 캠페인 화면 머리의 "진행 초기화" 는 지금처럼 두 번 누르기("정말 초기화할까요?")로 둔다.

### 스타일 (docs/art/ui-style.md)

14. 안내 카드: 제목 `h.2` `text.1`, 안내 문장 `small` `text.2`. 틀 없이 칸 맨 위에.
15. 병종 카드: `frame.ally` 축소판(안쪽 여백 16), 카드 사이 12.
    - 머리: 병종 무기 아이콘 40px (ui-style.md 9, `ally`) + 이름 `h.2`. 오른쪽에 능력치 줄 `small` `text.2`, 숫자는 `text.1`.
    - 강화 칸은 카드 안에 가로로 나란히(그 병종의 강화 수만큼), 각 칸 `frame.tip` 바탕.
16. 강화 칸 안: 이름 `body` Bold `text.1`, 오른쪽 가격 `num.2` `light` "{n} 금화" 또는 `small` `light` "보유". 효과 설명 `small` `text.2`. 스폰 표시 `small`: 물려받음 `spawn`, 물려받지 않음 `text.3`, 앞에 `Status_Vampiric_01` 16px (같은 색).
17. 버튼 (ui-style.md 6):
    - "강화" = `btn.normal`. 금화가 모자라면 비활성, 호버 툴팁 "금화가 모자랍니다 ({가진}/{가격})" (새 `Text` 키 `camp.needGold`).
    - 확인 상태 "정말 살까요? N 금화" = `btn.danger` 선택됨 상태.
18. 사면 그 강화 칸 테두리가 0.2초 번쩍이고(ui-style.md 12 의 1단계 변화) `light` 로 남는다. 금화 숫자도 0.2초 번쩍인다.
19. 아직 강화가 안 열린 병종(병종이 해금되었지만 그 장을 클리어하기 전)은 카드를 두지 않는다 (지금과 같다). 6번 안내 한 줄은 `small` `text.3`.

## 정한 세부 (docs/design 에 없는 것)

- **확인 방식은 두 번 누르기다(10번).** 근거: 진행 초기화와 전투 나가기가 이미 같은 방식이다. 같은 동작은 같은 방식으로 한다. 시간은 나가기와 같은 2.5초다.
- **스폰 계승 문장을 안내 카드에 넣는다(2번).** 근거: 방어 예외가 생겨 "능력치는 모두 물려받는다" 가 틀리게 됐다.
- **병종 글자 배지 대신 무기 아이콘(15번).** 근거: ui-style.md 9 가 병종을 무기 아이콘으로 정했다. 장 선택·배치 화면과 같은 표시를 쓴다. 5번의 "글자 배지" 는 이 아이콘으로 읽는다.
- **가격·보유는 `light`(16번).** 근거: ui-style.md 2-2 의 4 "`light` 는 광원·재화에만". 금화는 재화다.
