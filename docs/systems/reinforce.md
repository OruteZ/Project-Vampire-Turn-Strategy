# 아군 증원 배치

> 출처: docs/design/combat.md, docs/design/units.md, docs/design/map.md (커밋 f7fc7f8). 이슈 #103 (사용자 원문 "스테이지 중간에 시작할때처럼 아군배치가 가능한 시스템"), 트리거는 docs/systems/triggers.md (#113)
> 목적: 전투 중간 목표를 이루면 인구가 늘고, 시작할 때처럼 배치 단계가 한 번 더 열려 잃은 유닛을 채우거나 새 전선을 만들 수 있게 한다.

## 요구사항

### 1. 데이터

1. 스테이지에 아군 증원 목록이 있다. 하나 = 트리거 id(triggers.md 1, 턴·칸 도달·처치), 늘어나는 인구 `pop`(1 이상), 늘어나는 은 `silver`(0 이상), 증원 배치 칸 목록.
2. 증원 배치 칸은 걸을 수 있는 칸이다. 지도의 배치 구역(`d`)이 아니어도 된다.

### 2. 언제

1. 트리거가 이루어지면, 그 뒤 처음 오는 **아군 페이즈 시작**(적 페이즈가 끝나고 턴이 넘어간 직후, 흡혈 표적이 정해진 뒤)에 증원 배치 단계가 열린다. 턴 조건 n 이면 n 번째 적 페이즈 다음, 곧 n+1 턴 아군 페이즈다.
2. 같은 때에 여러 증원이 열리면 하나로 합친다(인구·은을 더하고 칸을 합친다).
3. 증원 배치 단계에서는 배치 단계와 같은 일만 할 수 있다: 편성 목록에서 고르고 증원 배치 칸의 빈 칸에 놓기, 이번에 놓은 유닛 옮기기·회수, 이번에 놓은 유닛 모두 회수. 예시 편성은 없다. 이미 싸우던 아군은 옮기거나 회수할 수 없다.
4. "배치 완료"(Space)를 누르면 아군 페이즈로 돌아간다. 아무도 놓지 않아도 된다. 새로 놓은 유닛은 그 턴에 바로 움직이고 행동할 수 있다(전투 시작 때와 같다).

### 3. 인구

1. 인구 한도 = 스테이지 인구 + 지금까지 열린 증원의 `pop` 합. 은도 같다.
2. 쓴 인구 = **지금 살아 있는 아군**의 인구 합(지금 규칙 그대로). 그래서 잃은 유닛의 인구는 다시 쓸 수 있다. 스폰이 된 아군, 처형한 아군도 아군이 아니므로 세지 않는다. 호위 목표 유닛은 세지 않는다.

### 4. 화면

1. 아직 열리지 않은 증원 배치 칸은 전투 내내 아군 색 점선으로 칠한다(`Mark.Reinforce`). 칸 위에 올리면 카드: "아군 증원 · 인구 +{0}" 과 조건 문장(triggers.md 1-5 와 같은 문장).
2. 증원 배치 단계가 열리면 배너 `banner.reinforce` "증원 도착", 기록 `log.reinforce` "증원이 도착했다. 인구 +{0}, 표시한 칸에 배치하라." 배치 구역 표시(파란 칸)는 증원 배치 칸만 칠한다.
3. 화면은 배치 화면과 같다. 다른 점: 인구 칸이 늘어난 한도를 보이고, 예시 편성 버튼이 없고, 오른쪽 아래 버튼이 `battle.reinforceDone` "배치 완료".
4. 새로 놓은 유닛의 이름은 같은 병종 번호를 이어서 매긴다(검사 3).

### 5. 문장 (Text 표 새 키)

| 키 | 한국어 | English |
|---|---|---|
| `banner.reinforce` | 증원 도착 | Reinforcements |
| `log.reinforce` | 증원이 도착했다. 인구 +{0}, 표시한 칸에 배치하라. | Reinforcements arrive. +{0} population: deploy them on the marked hexes. |
| `log.reinforced` | 증원 {0}명이 합류했다. | {0} reinforcements join. |
| `battle.reinforceDone` | 배치 완료 | Done deploying |
| `unit.card.reinforce` | 아군 증원 · 인구 +{0} | Reinforcements · +{0} population |

## 정한 세부

- **쓴 인구는 살아 있는 아군으로 센다(3-2).** 근거: #103 요청 "손실된 유닛 상황에 맞게 충원". 잃은 만큼 다시 채울 수 있어야 전략을 다시 짠다.
- **증원은 아군 페이즈 시작에 연다(2-1).** 근거: 적 차례 도중이나 아군이 이미 움직인 뒤에 열리면 배치가 그 턴 계산을 흔든다. 시작에 열면 "시작할 때처럼" 이 된다. 흡혈 표적은 이미 정해져 있으니 새 유닛으로 표적을 막거나 피하게 할 수 있다.
- **이미 싸우던 아군은 옮기지 못한다(2-3).** 근거: 옮길 수 있으면 증원이 "공짜 순간 이동" 이 된다.
- **증원 칸은 지도 글자가 아니라 좌표 목록.** 근거: 지킬 칸·트리거 칸과 같은 방식. 지도 글자를 늘리지 않는다.
- **중간 목표 = 트리거.** 칸 도달(위험한 곳에 가면), 처치(n 명 잡으면), 턴(버티면). #103 의 "위험한 자리의 소환 재화" 는 칸 도달 + `silver` 로 낼 수 있다.
