# 스폰 변이

> 출처: docs/design/vampire.md, docs/design/units.md, docs/design/progression.md (커밋 f7fc7f8)
> 목적: 아군이 언제 시신이 되고, 시신이 언제 어떤 능력치의 스폰으로 일어나는지 정한다.

## 요구사항

### 변이 조건

1. 아군이 **뱀파이어나 스폰에게** 죽으면 죽은 칸에 시신이 남는다.
2. 아래 경우에는 시신이 남지 않는다(변이 없음).
   - 하수인(스켈레톤)에게 죽었을 때
   - 빛 칸에서 죽었을 때(빛 칸 정의는 docs/systems/light.md)
   - 아군의 공격으로 죽었을 때(아군 공격). 아군 공격은 공격 행동을 쓰고, 적을 칠 때와 같은 피해 계산(공격 − 방어, 매복·돌격·밀집 대형 포함, 최소 1)으로 피해를 준다. 한 번에 죽지 않으면 그대로 다친 채 남는다. 적 처치에 붙는 부가효과(연속 공격·포식·비산)는 아군 대상에선 나지 않는다 (2026-11-12 리뷰 "변이 방지가 너무 쉬워지지 않도록", #119)
3. 보름달 흡혈로 먹힌 아군은 뱀파이어에게 죽은 것이다. 흡혈 표적은 빛 밖에서만 먹히므로 항상 시신이 남는다.
4. 적(스켈레톤, 스폰, 뱀파이어)은 죽어도 시신이 남지 않는다.

### 시신

5. 시신은 칸을 막는다. 아군도 적도 시신 칸으로 들어가거나 지나갈 수 없다.
6. 시신은 공격할 수 없다. 시신을 부수는 기능은 전역 규칙으로 두지 않는다(일부 특수 유닛만 가질 수 있다. 그 유닛의 기획서에 쓴다). 지금은 장의사의 **수습**(바로 옆 시신을 없앤다)뿐이다 (docs/content/units.md 4-3).

### 일어나는 때

7. 다음 **적 페이즈가 시작될 때** 그때 있는 모든 시신이 같은 칸에서 스폰으로 일어난다. 달이 차는 것보다 먼저 일어난다.
8. 일어난 그 적 페이즈에는 행동하지 않는다. 그다음 적 페이즈부터 움직이고 공격한다.

### 스폰 능력치

9. 스폰은 원본 아군의 값을 이렇게 물려받는다. 원본 값은 능력치 강화가 반영된 값이다.

| 항목 | 스폰 값 |
|---|---|
| 체력 | 원본의 최대 체력. 일어날 때 가득 찬 상태 |
| 공격 | 원본의 공격 |
| 방어 | **0 고정** |
| 이동 | 원본의 이동 |
| 사거리 | **1 고정**(원거리 공격 불가) |
| 은탄(언데드 추가 공격) | 없음 |
| 치료량 | 없음 |
| 기술 (강화로 얻은 것과 병종 기본 기술 모두: 창벽, 매복 사격, 베어 넘기기, 돌격, 밀집 대형, 성수 세례, 성스러운 매장, 수습, 밤샘 수습, 치료) | 없음 |

10. 이름은 `스폰(<원본 이름>)` 이다. 예: `스폰(기사 2)`.
11. 스폰은 적 진영이다. 스폰에게 죽은 아군도 1번에 따라 변이한다(연쇄).

## 화면에 나오는 문장

12. 이 기획서의 값이 바뀌면 같은 내용을 말하는 화면 문장도 바뀐다. 문장 전체의 위치는 화면 기획서(docs/ui/battle-hud.md)가 정한다. 바꿔야 하는 문장:
    - **규칙 요약 한 줄:** "스폰은 원본의 체력·공격·이동을 물려받고, 방어는 0 이며 근접 공격만 합니다. 기술 강화는 물려받지 않습니다."
    - **시신 카드:** "체력 {최대 체력}, 공격 {공격}, 이동 {이동}을 물려받고 방어 0, 근접 공격만 합니다. 일어나기 전에 주변 아군을 물리거나 맞을 준비를 하세요."
    - **스폰 카드 설명:** "{원본}의 체력·공격·이동을 물려받았다. 방어는 0 이고 근접 공격만 한다. 죽인 아군을 스폰으로 만든다."

## 정한 세부 (docs/design 에 없는 것)

- **이동은 물려받는다.** 근거: vampire.md "주력 유닛일수록 더 강한 적이 된다". 이동은 그 위협의 일부이고, units.md 는 방어와 사거리만 바꾼다.
- **은탄은 물려받지 않는다.** 근거: 은탄은 언데드에게 더하는 공격이다. 스폰은 아군만 공격하므로 의미가 없다.
- **일어날 때 체력은 가득 찬다.** 근거: 원본이 죽은 순간의 체력은 0 이다. 최대 체력을 물려받는 것이 "체력을 계승한다" 의 뜻이다.
- **병종 기본 기술(수습, 치료)과 치료량도 물려받지 않는다(#99).** 근거: progression.md "기술 강화는 물려받지 않는다" 를 기본 기술에도 똑같이 적용해, 스폰은 늘 체력·공격·이동만 가진 근접 몸이 되게 한다. 플레이어가 시신을 보고 스폰을 바로 셀 수 있다.
