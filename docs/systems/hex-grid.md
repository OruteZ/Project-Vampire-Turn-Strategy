# 육각 타일 이동·시야

> 출처: docs/design/map.md (커밋 f7fc7f8). 이슈 #113
> 목적: 지형마다 이동 비용을 정한다. 보드는 flat-top, odd-q (`Core/Hex.cs`).

## 요구사항

### 1. 지형과 이동

| 글자 | 지형 | 들어갈 때 이동 | 빛 | 배치 |
|---|---|---|---|---|
| `.` | 평지 | 1 | | |
| `d` | 배치 구역 | 1 | | 배치 가능 |
| `T` | 횃불 | 1 | 자기와 이웃 | |
| `S` | 햇빛 | 1 | 자기 | |
| `,` | **거친 땅 (새)** | **2** | | |
| `#` | 벽 | 못 감 | | 원거리 공격도 막는다 (4-1) |
| `_` | **틈 (#144)** | 못 감 | | 배치·증원·대상 불가. 원거리 공격은 넘어간다 |

0. **규칙 칸과 모습 칸 (2026-11-17, #144).** 지도 글자는 칸이 **어떻게 동작하나**만 정한다. 이동도 사격도 막는 칸은 모두 `#` 벽, 이동만 막고 사격은 넘기는 칸은 모두 `_` 틈이다. 그 칸이 **무엇으로 보이나**(바위·성벽 / 물·낭떠러지·낮은 담)는 레벨 디자인이 아니라 꾸미기 쪽 모습 칸이 정한다(docs/art/stage-dressing.md 8). 전투 규칙은 모습 칸을 읽지 않는다. 옛 글자 `~`(물)는 없앴다: 규칙은 `_`, 모습은 물.
1. 이동 가능한 칸 = 들어간 칸들의 비용 합이 이동력 이하인 칸. 거친 땅은 이동력이 1 만 남았으면 못 들어간다. **단, 첫 한 걸음은 비용과 상관없이 늘 갈 수 있다**(2026-11-13: 기본 이동이 1 이 되어 이 규칙이 없으면 거친 땅이 벽이 된다). 그래서 거친 땅은 이동 2 이상 유닛만 늦춘다.
2. 모든 유닛(아군, 하수인, 스폰, 뱀파이어, 목표 유닛)에 같다.
3. 적 AI 의 "걸음 수"(ai.md 3절)는 이 비용 합이다. 비용이 같으면 지금 이웃 순서대로 먼저 찾은 칸(`Hex.cs` 순서를 지킨다).
4. 공격 사거리·흡혈 거리·치료 거리는 지형과 상관없는 칸 거리 그대로다. 단 사거리 2 이상인 공격은 4-1 을 따른다.
   - **4-1. 시야 (2026-11-17, #113·#132).** 사거리 2 이상인 공격(아군·적 모두, 아군 공격 포함)은 쏘는 칸과 맞는 칸의 중심을 잇는 곧은 선 위에 벽(`#`)이 있으면 닿지 않는다. 틈(`_`)·유닛·시신은 막지 않는다. 선이 두 칸의 경계를 정확히 지나면 어느 한쪽이라도 열려 있으면 닿는다. 바로 옆 칸(거리 1)은 늘 닿는다. 흡혈과 치료는 시야를 보지 않는다. 코드 `Board.Sees`, `Battle.InRange`. 근거: 봇으로 재 보니 궁수만 쌓은 편성이 벽 너머로 쏴 손실 없이 이겼다.
   - **4-2. 붙은 적은 못 쏜다 (2026-11-17).** 사거리 2 이상인 공격은 바로 옆 칸(거리 1)을 칠 수 없다(4-1 의 "바로 옆 칸은 늘 닿는다" 는 사거리 1 인 근접 공격 이야기다). 아군 원거리와 스켈레톤 궁수 모두 같다. 근거: 무작위 빌드 400판에서 원거리 위주 편성이 장 안에서 견줘도 승률이 0.2~0.3 높았다. 넣은 뒤 농민 궁수 쌓기는 −0.25, 궁수는 +0.2 안팎(다른 정예와 비슷).
5. 이동 범위 표시는 지금처럼 이동 가능한 칸을 칠한다. 거친 땅 칸은 유닛 카드·칸 정보에 "거친 땅: 들어갈 때 이동 2" 를 보인다 (`terrain.rough` "거친 땅" / "Rough ground", `terrain.rough.note` "들어갈 때 이동 2" / "Costs 2 movement to enter").
6. 모습: 장 컨셉에 따라 진흙·덤불·자갈 비탈·얕은 여울. 에셋은 docs/areas/art-assets.md 에서 고른다(#101 지형 작업과 맞춘다).

## 정한 세부

- **거친 땅 비용 2.** 근거: map.md "들어갈 때 이동력이 1 더 드는 타일".
- **막힌 칸은 규칙 둘(벽·틈)뿐이고 모습은 따로다 (#144).** 근거: 사용자 "레벨디자인을 할때는 시스템상으로 같은 타일은 통일하고, 에셋 디자인을 하는 쪽에서만 그 차이를 구분". 옛 물 `~` 와 빈 칸 `_` 는 규칙이 같아서 하나로 합쳤다. 건널 수 있는 여울은 거친 땅으로 그린다.
- **틈은 벽이 아니라 "칸이 없음".** 근거: #113 리뷰 "맵 크기는 유지하고, 빈 타일을 설치해서 전투 동선이 나오도록". 판 크기는 두고 꺾인 길·갈림길을 낸다. 화살·흡혈은 그 위를 넘어간다.
