# 육각 타일 이동·시야

> 출처: docs/design/map.md (커밋 f7fc7f8). 이슈 #113
> 목적: 지형마다 이동 비용을 정한다. 보드는 flat-top, odd-q (`Core/Hex.cs`).

## 요구사항

### 1. 지형과 이동

| 글자 | 지형 | 들어갈 때 이동 | 빛 | 배치 |
|---|---|---|---|---|
| `.` | 평지 | 1 | | |
| `d` | 배치 구역 | 1 | | 배치 가능 |
| `T` | 횃불 | 1 | 자기와 이웃 | |
| `S` | 햇빛 | 1 | 자기 | |
| `,` | **거친 땅 (새)** | **2** | | |
| `#` | 막힘 | 못 감 | | |
| `~` | 물 | 못 감 | | |
| `_` | **빈 칸 (새, #113)** | 못 감 | | 배치·증원·대상 불가. 바닥 없는 낭떠러지로 보인다 (바닥·격자·소품 없음) |

1. 이동 가능한 칸 = 들어간 칸들의 비용 합이 이동력 이하인 칸. 거친 땅은 이동력이 1 만 남았으면 못 들어간다.
2. 모든 유닛(아군, 하수인, 스폰, 뱀파이어, 목표 유닛)에 같다.
3. 적 AI 의 "걸음 수"(ai.md 3절)는 이 비용 합이다. 비용이 같으면 지금 이웃 순서대로 먼저 찾은 칸(`Hex.cs` 순서를 지킨다).
4. 공격 사거리·흡혈 거리·치료 거리는 지형과 상관없는 칸 거리 그대로다.
5. 이동 범위 표시는 지금처럼 이동 가능한 칸을 칠한다. 거친 땅 칸은 유닛 카드·칸 정보에 "거친 땅: 들어갈 때 이동 2" 를 보인다 (`terrain.rough` "거친 땅" / "Rough ground", `terrain.rough.note` "들어갈 때 이동 2" / "Costs 2 movement to enter").
6. 모습: 장 컨셉에 따라 진흙·덤불·자갈 비탈·얕은 여울. 에셋은 docs/areas/art-assets.md 에서 고른다(#101 지형 작업과 맞춘다).

## 정한 세부

- **거친 땅 비용 2.** 근거: map.md "들어갈 때 이동력이 1 더 드는 타일".
- **물은 그대로 못 지나간다.** 근거: map.md 의 이동 불가 타일. 건널 수 있는 여울은 거친 땅으로 그린다.
- **빈 칸은 벽이 아니라 "칸이 없음".** 근거: #113 리뷰 "맵 크기는 유지하고, 빈 타일을 설치해서 전투 동선이 나오도록". 판 크기는 두고 꺾인 길·갈림길을 낸다. 사거리는 4번대로 칸 거리라 화살·흡혈은 그 위를 넘어간다.
