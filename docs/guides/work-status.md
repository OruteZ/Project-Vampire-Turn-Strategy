# 작업 현황 (GitHub 이슈)

- 제목: `작업: <기능명>`
- 라벨: `작업` + 상태 하나(`진행 중` / `막힘`). 에디터(MCP)가 필요하면 `에디터 필요`
- 커밋 메시지에 `#번호`

## 본문 형식

```markdown
> 사용자 원문 인용

## 할 일
- [ ] 항목
- [x] 끝낸 항목 (확인: 어떻게 확인했는지)
- [ ] 미룬 항목 — 이유

## 관련
- 안내서: docs/areas/<분야>.md
- 기획: docs/design/<파일>
```

막히면 라벨을 `막힘` 으로 바꾸고 이유를 댓글로. 끝나면 결과(문서·커밋)를 댓글로 달고 닫는다.
