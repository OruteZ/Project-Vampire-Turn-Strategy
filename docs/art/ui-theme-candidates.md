# UI 테마 후보

출처: docs/design/art.md, docs/design/ui.md, docs/design/campaign.md, docs/design/vampire.md (커밋 f7fc7f8)

> 파이프라인 1단계 결과물 (#24). 사용자가 하나를 고르거나 섞어서 `docs/design/` 에 쓰면, 그 방향으로 레퍼런스 수집(3단계)과 UI 스타일 기획서(`docs/art/ui-style.md`, 4단계)를 시작한다. 고르고 나면 이 문서는 지운다.

## 모든 후보에 공통인 조건

- **바탕은 Synty INTERFACE Dark Fantasy 키트** (`Assets/Synty/InterfaceDarkFantasyMenus`, `InterfaceDarkFantasyHUD`). 틀 스프라이트가 3D 에셋처럼 면이 깎인 로우폴리 질감이라 보드와 톤이 맞는다.
- 키트에는 장식(greeble)이 많다: 악마 해골 25종, 소용돌이 23종, 가시·뿔·촉수·오망성 등. **대부분 "악" 쪽 상징이다.** 플레이어는 백작을 치러 가는 마을 토벌대(campaign.md)라서, 이 장식을 어디에 쓸지가 후보마다 갈리는 지점이다.
- 키트 글꼴(LT Museum, Markazi, Pirata One)은 라틴 문자만 있다. 한글은 #16 계획대로 제목 Nanum Myeongjo, 본문 IBM Plex Sans KR 를 쓰고, 키트 글꼴은 숫자·영문 장식에만 쓸 수 있다.
- ui.md 의 "중요도 차등"은 세 단계로 나눠 보이게 한다: **1단계** 지금 결정에 필요한 것(선택 유닛·대상의 체력·이동력, 보름달, 턴 종료), **2단계** 참고(전황 수치, 전투 기록), **3단계** 배경(규칙 요약, 안내 문구). 후보마다 이 세 단계를 무엇으로 가르는지 적었다.
- 보드가 주인공이다. 화면 가장자리 UI 는 보드를 가리지 않게 좁게 두고, 장식은 틀의 모서리에만 쓴다.
- 지금 HTML 데모 색(`--ink #15131a`, `--candle #e3a84b`, `--blood #c8304a`, `--spawn #a650c4`)은 출발점일 뿐, 후보가 이기면 바뀐다.

## 후보 A. 백작의 문장 — 고딕 귀족

**한 줄**: 플레이어가 백작의 영지에 들어선다. UI 는 성의 장식처럼 화려하고 위압적이다.

| 항목 | 내용 |
|---|---|
| 색 | 바탕 짙은 자주검정 `#140d12`, 주색 핏빛 `#9e1b2f`, 금속 낡은 금 `#b8904a`, 글자 뼈빛 `#ebe3d2` |
| 틀 | 키트의 가시 틀(`Frame_Box_Large`), 방패(`Shield`), 문장(`Crest`) 을 그대로. 모서리마다 소용돌이·해골 장식 |
| 글꼴 | 제목 명조를 크게, 숫자는 LT Museum |
| 중요도 | 1단계 = 금 테두리 + 큰 글자, 2단계 = 장식 없는 틀, 3단계 = 틀 없이 흐린 글자 |
| 키트 활용 | 가장 많음. 거의 손대지 않고 쓴다 |
| 참고작 | Bloodborne 메뉴, Castlevania 계열의 고딕 장식 |
| 위험 | 화면이 플레이어 편이 아니라 뱀파이어 편처럼 보인다. 장식이 많아 "깔끔하게"(ui.md)와 부딪히기 쉽다 |

## 후보 B. 토벌대의 기록 — 횃불과 양피지

**한 줄**: UI 는 토벌대가 들고 다니는 작전 일지다. 따뜻한 횃불빛 안이 아군, 그 밖이 어둠이다.

| 항목 | 내용 |
|---|---|
| 색 | 바탕 그을린 나무 `#1a1510`, 종이 `#d9c9a3`, 주색 횃불 호박색 `#e3a84b`, 적 표시만 핏빛 `#c8304a` |
| 틀 | 키트에서 장식이 적은 막대·상자 틀(`Bar`, `Box`, `Frame_Bracket`) 을 나무·쇠 색으로 물들인다. 악마 장식은 쓰지 않는다. 밀랍 봉인, 못, 가죽끈 같은 소품은 키트에 없어 따로 그려야 한다 |
| 글꼴 | 제목 명조, 본문 고딕. 전투 기록은 손글씨 느낌을 살짝 |
| 중요도 | 1단계 = 횃불빛(밝은 호박색) 위에, 2단계 = 종이 위 검은 글자, 3단계 = 어둠 속 흐린 글자. **광원 시스템과 같은 말로 말한다** |
| 키트 활용 | 중간. 틀만 쓰고 장식은 버린다. 소품 스프라이트 몇 장은 새로 필요 |
| 참고작 | Darkest Dungeon(양피지·횃불 게이지), The Banner Saga(원정대 일지), Desperados III(작은 HUD) |
| 위험 | 키트의 강점(장식)을 거의 버린다. 따로 그릴 소품이 늘어 아트 일이 커진다 |

## 후보 C. 달과 피 — 두 진영 대비 (추천)

**한 줄**: 아군 UI 는 차가운 달빛과 쇠, 적 UI 는 피와 악마 장식. 화면을 보면 어느 쪽 정보인지 색과 틀만으로 안다.

| 항목 | 내용 |
|---|---|
| 색 | 바탕 밤하늘 `#12131a`, 아군 은빛 쇠 `#8fb0cc` · 뼈빛 글자 `#ebe3d2`, 적 핏빛 `#c8304a`, 스폰 보라 `#a650c4`, 보름달 창백한 금 `#eadcae` |
| 틀 | 아군 패널은 장식 없는 깎인 틀(`Frame_Bar`, `Frame_Box_Medium`)을 쇠색으로. 적 정보 패널(적 스펙, 뱀파이어, 보스 체력)에만 키트의 해골·가시·촉수 장식. 스폰은 아군 틀에 보라 균열 |
| 글꼴 | 제목 명조, 본문 고딕, 숫자는 굵고 크게 |
| 중요도 | 1단계 = 화면 중앙 하단에 큰 숫자, 진영 색으로. 2단계 = 가장자리 좁은 패널. 3단계 = 접힌 패널. 진영 색은 1·2단계에만 쓰고 3단계는 회색 |
| 상징 | **보름달 게이지를 화면 위 가운데 큰 원**(`Frame_Ring`)으로. 차오를수록 핏빛이 번진다 (vampire.md "보름달이 차면 붕괴가 시작될 수 있다는 압박") |
| 키트 활용 | 많음. 장식을 적 쪽에만 몰아 쓴다 |
| 참고작 | Into the Breach(적 정보 가독성), Gloomhaven 디지털판(적 카드 틀), Desperados III(작은 HUD) |
| 위험 | 진영 색 두 벌을 지켜야 해서 규칙이 늘어난다. 스폰(아군이었다가 적)이 두 진영 사이에서 어떻게 보일지 정해야 한다 |

**추천 이유**: ui.md 의 "중요도 차등"과 "적 스펙 공개"를 진영 대비로 한꺼번에 푼다. 키트의 악마 장식이 적 쪽에 쓰여 이야기(토벌대 대 백작)와 맞고, 보름달이라는 이 게임만의 압박을 화면 상징으로 만든다.

## 섞을 수 있는 것

- B 의 "횃불빛 = 1단계" 규칙을 C 에 넣을 수 있다 (아군 쪽 강조를 은빛 대신 횃불빛으로).
- A 의 문장(`Crest`)은 어느 후보든 메인 메뉴·스테이지 선택 같은 메뉴 화면에서는 쓸 수 있다.
