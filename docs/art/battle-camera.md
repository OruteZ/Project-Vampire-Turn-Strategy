# 전투 카메라 연출

> 출처: docs/design/overview.md, combat.md, vampire.md, ui.md, art.md (커밋 f7fc7f8)
> 후보 조사: docs/art/battle-camera-candidates.md. 이 문서는 사용자가 고른 A 등급(1~4)과 B 등급 5개(5~9, 턴 전환 줌은 뺌)를 다룬다 (#97).

## 1. 공통 규칙

1. 기본 시점은 **플레이어 시점**(11절)이다. 처음과 R 키 뒤에는 보드 전체가 보드 영역에 들어오는 맞춤 시점(stage-dressing.md 1-4). 연출은 이 시점에서 **같은 각도로 평행 이동·앞으로 당기기**만 한다. 연출은 회전·기울임을 하지 않는다.
2. **재생 템포**: 모든 유닛 행동(걷기 한 칸·타격·쓰러짐·변이·관 열림·배너)의 대기는 옛 HTML 데모 값의 **2배**다(`BattleView.Pace`). 카메라는 이 대기 동안 움직인다. 배속은 F 키와 설정 창(docs/ui/settings.md)의 1·2·4배다.
3. 재생 속도(`speed`)를 따른다. `speed = 0`(즉시)이면 연출이 없다.
4. 재생이 끝나 플레이어가 입력할 때(재생 대기열이 빈 뒤)는 항상 기본 시점으로 돌아온다. 예외는 5절 보름달 예고, 8절 전투 시작 훑기, 9절 전투가 끝난 뒤다.
5. 움직임은 부드럽게 따라간다(감쇠 0.6초). 순간 이동하지 않는다.
6. 무작위 없음(overview.md): 같은 상황이면 같은 움직임이다.
7. **붉은 비네트는 뱀파이어가 아군을 흡혈하는 모션(5절 실행 2)에만** 쓴다. 다른 연출에는 비네트가 없다.

용어:
- **당김 정도(pan)**: 0 이면 기본 시점, 1 이면 대상이 보드 영역 한가운데에 온다.
- **가까이(zoom)**: 기본 거리 대비 앞으로 나간 비율. 0.3 이면 거리 70%.

## 2. 변이 (스폰이 일어남)

| 항목 | 값 |
|---|---|
| 때 | `Rose` 이벤트 (적 턴 시작, 시신이 스폰으로 일어날 때) |
| 대상 | 일어나는 칸 |
| 당김 / 가까이 | 0.6 / 0.35 |
| 색 | 화면 채도 -60. 일어나는 동안 들어갔다가 다음 이벤트에서 빠진다 (비네트 없음) |
| 길이 | 변이 대기 1.2초 (1절 2) |

## 3. 연쇄 변이

1. 한 적 턴에 변이가 여럿이면 2절을 칸마다 차례로 한다(일어나는 순서대로).
2. 두 번째부터는 가까이를 0.25 로 줄인다(훑는 느낌). 색은 변이가 다 끝날 때까지 유지한다.

## 4. 적 턴 따라가기

| 항목 | 값 |
|---|---|
| 때 | 적 진영 유닛의 `Walk`, 적이 공격자인 `Hit` |
| 대상 | `Walk` 는 걷는 유닛의 현재 위치(걷는 동안 따라감), `Hit` 는 공격자와 표적의 가운데 |
| 당김 / 가까이 | 0.3 / 0.1 (살짝만. 보드 대부분이 계속 보여야 한다) |
| 끝 | 다음 적 행동이 오면 그 대상으로 옮겨 가고, 플레이어 턴 배너에서 기본 시점으로 돌아온다 |

아군 행동(플레이어가 명령한 이동·공격)은 따라가지 않는다. 플레이어가 이미 보고 있는 곳이다.

## 5. 보름달 흡혈

### 예고 (플레이어 턴)
1. 흡혈 표적이 새로 정해진 직후(다음 적 턴에 보름달이 차서 표적이 생긴 때), 재생이 끝나면 뱀파이어와 표적의 가운데로 2초 당겼다가 돌아온다.
2. 당김 / 가까이: 0.4 / 0.15. 비네트 없음. 이 동안에도 입력은 막지 않는다.
3. 같은 표적에는 한 번만 한다.

### 실행 (적 턴)
1. 보름달 배너(`banner.fullMoon`)가 뜨면 뱀파이어와 표적의 가운데로 당긴다. 당김 / 가까이: 0.5 / 0.25. 비네트 없음.
2. **흡혈 모션**(흡혈 타격): 당김 / 가까이 0.6 / 0.35, 붉은 비네트를 강하게(세기 0.6, 부드러움 0.7, 색 MoonBlood) 넣는다. 흡혈 타격 대기는 일반 타격보다 1.6초 더 길다. 표적이 쓰러지면 비네트가 빠진다.
3. 흡혈이 실패하면(표적이 빛 안·멀리) 비네트 없이 1번 당김만 하고, 뱀파이어는 4절대로 따라간다.

## 6. 타격 흔들림과 짧은 멈춤

1. **큰 공격에서만** 화면을 흔들고 아주 짧게 멈춘다(멈춤 = 게임 시간 정지). 기본 공격에는 흔들림·멈춤이 없다.
2. 큰 공격 = 피해 **4 이상**인 타격, 또는 흡혈. 기준점 근거: 지금 데이터의 보통 피해는 1~3 이고, 기사, 돌격, 사냥꾼의 언데드 추가피해, 방어가 낮은 아군을 치는 뱀파이어 공격이 4 이상이다.
3. 큰 공격: 흔들림 세기 = 기본 거리의 0.6%, 0.4초에 걸쳐 줄어듦. 멈춤 0.09초.
4. 흔들림은 화면 가로·세로로만, 고정된 사인 모양(무작위 없음). 재생 템포(1절 2)와 상관없이 실제 시간으로 잰다.
5. 설정 창의 "화면 흔들림"(끔·약하게·보통 = 0·0.5·1)을 세기에 곱한다 (docs/ui/settings.md 6).

## 7. 중요한 처치 줌

1. 뱀파이어·스폰이 쓰러질 때(`Died`), 그 칸으로 당긴다. 당김 / 가까이 0.5 / 0.3.
2. 쓰러진 뒤 1초(0.5초 × 템포 2배) 더 머문 다음 다음 재생으로 간다.
3. 하수인(해골)·아군이 쓰러질 때는 하지 않는다. 마지막 처치는 9절이 대신한다.

## 8. 전투 시작 훑기

1. 전투 화면이 열리면(배치 단계 시작) 카메라가 뱀파이어 가까이(당김 / 가까이 0.7 / 0.35)에서 시작해 1.4초 머문 뒤, 맵을 지나 기본 시점으로 내려앉는다(감쇠 0.6초).
2. 그 사이 마우스 버튼이나 키를 누르면 바로 기본 시점으로 돌아간다(배치 클릭이 어긋나지 않게).

## 9. 승리·패배 마무리

1. 전투를 끝내는 마지막 일격(뱀파이어를 쓰러뜨리는 타격, 또는 마지막 아군을 쓰러뜨리는 타격)에서 게임 시간을 0.35배로 1.6초(실제 시간) 늦춘다.
2. 그 표적으로 당긴다: 당김 / 가까이 0.8 / 0.45. 쓰러진 뒤 2초 더 머문다.
3. 전투가 끝난 뒤(결과 화면)에도 카메라는 그 자리에 머문다.
4. 이때는 6절의 멈춤을 하지 않는다(느린 화면이 대신한다). 흔들림은 6절대로 큰 공격일 때만 한다.

## 10. 아군 직접 처치

1. 아군을 직접 처치하면(`popup.execute`) 그 아군 칸으로 당긴다: 당김 / 가까이 0.4 / 0.25.
2. 멈춤 0.12초, 그 뒤 1초(0.5초 × 템포 2배) 머문 뒤 쓰러진다.

## 11. 플레이어 시점 조작 (#117)

맵이 커져(20×16 등) 맞춤 시점에서 유닛이 너무 작다. 플레이어가 시점을 옮긴다. 연출(2~10절)은 이 시점 위에 더해지고, 끝나면 이 시점으로 돌아온다.

| 입력 | 동작 |
|---|---|
| 마우스 휠 | 확대·축소. 한 칸에 거리 ×0.85(확대)·÷0.85(축소). 커서 아래 땅이 화면에서 그 자리에 머문다. 가장 멀리 = 맞춤 거리, 가장 가까이 = 맞춤 거리의 0.3 |
| Q / E | 보는 점을 축으로 왼쪽·오른쪽 돌기, 초당 90°. 각도 제한 없음. 기울기(55°)는 그대로 |
| W A S D, 방향키 | 화면 방향으로 평행 이동, 초당 (지금 거리 × 0.8). 보는 점은 보드 칸 범위 밖으로 나가지 않는다 |
| R | 맞춤 시점으로 (거리·각도·위치 모두) |

1. 움직임은 0.12초 감쇠로 따라간다(연출의 0.6초보다 빠르게, 조작이 늦게 느껴지지 않게).
2. 휠은 커서가 UI 위에 있으면 쓰지 않는다. 키는 늘 받는다.
3. 재생 중에도 조작할 수 있다. 연출 끔(settings.md 5)과 상관없다.
4. 새 전투(`BattleView.Begin`)는 맞춤 시점에서 시작한다.
5. 남쪽 둘레를 낮게 둔 규칙(stage-dressing.md 1-5)은 돌린 시점에선 지켜지지 않는다. 높은 소품이 유닛을 가리면 사용자 확인 뒤 다룬다.

- 2026-11-09 사용자 확인(#97): 적 움직임이 빨라 어지러움 → 템포 2배·감쇠 0.6초, 비네트는 흡혈 모션만.
- 수치(당김·가까이·색)는 조사 원칙 "드물수록 세다"에 따라 변이 > 보름달 > 적 따라가기 순으로 세기를 둔다.
- 설정 창의 "카메라 연출" 끔이면 2~5·7~10절과 6절 멈춤을 하지 않는다 (docs/ui/settings.md 5).
