# 전투 카메라 연출

> 출처: docs/design/overview.md, combat.md, vampire.md, ui.md, art.md (커밋 f7fc7f8)
> 후보 조사: docs/art/battle-camera-candidates.md. 이 문서는 사용자가 고른 A 등급(1~4)과 B 등급 5개(5~9, 턴 전환 줌은 뺌)를 다룬다 (#97).

## 1. 공통 규칙

1. 기본 시점은 **플레이어 시점**(11절)이다. 처음과 R 키 뒤에는 보드 전체가 보드 영역에 들어오는 맞춤 시점(stage-dressing.md 1-4). 맞춤 규칙 (#150 보고서 A3): 모든 칸의 꼭짓점이 보드 영역 안에 드는 가장 가까운 거리(가깝게 시작해 1% 씩 물러난다)로, 원근 때문에 아래쪽이 커지는 만큼 보는 점을 옮겨 위아래 여백을 고르게 한 뒤 다시 맞춘다(4번). 카메라 맞춤 영역은 `.board-area`(150/190)보다 위아래가 좁다: 위 250(보름달 게이지와 그 아래 두 줄 밑), 아래 380(배치 화면의 배치 수·안내 줄 위, 판 기준). 꼭 맞추면 맨 윗줄·아랫줄이 이 HUD 밑으로 들어가기 때문이다. 1장(9×9) 16:9 에서 칸 범위가 화면 폭 37%·높이 59% 쯤 → 맞춤 영역 높이의 99%, 9장(13×12) 99%. 연출은 이 시점에서 평행 이동·앞으로 당기기를 하고, 14절의 드문 순간에만 대상을 축으로 돌고 낮춘다(각도 컷). 그 밖의 연출은 회전·기울임을 하지 않는다.
2. **재생 템포**: 모든 유닛 행동(걷기 한 칸·타격·쓰러짐·변이·관 열림·배너)의 대기는 옛 HTML 데모 값의 **2배**다(`BattleView.Pace`). 카메라는 이 대기 동안 움직인다. 배속은 F 키와 설정 창(docs/ui/settings.md)의 1·2·4배다.
3. 재생 속도(`speed`)를 따른다. `speed = 0`(즉시)이면 연출이 없다.
4. 재생이 끝나 플레이어가 입력할 때(재생 대기열이 빈 뒤)는 항상 기본 시점으로 돌아온다. 예외는 5절 보름달 예고, 8절 전투 시작 훑기, 9절 전투가 끝난 뒤다.
5. 움직임은 부드럽게 따라간다(감쇠 0.6초). 순간 이동하지 않는다.
6. 무작위 없음(overview.md): 같은 상황이면 같은 움직임이다.
7. **붉은 비네트는 뱀파이어가 아군을 흡혈하는 모션(5절 실행 2)에만** 쓴다. 다른 연출에는 비네트가 없다.

용어:
- **당김 정도(pan)**: 0 이면 기본 시점, 1 이면 대상이 보드 영역 한가운데에 온다.
- **가까이(zoom)**: 기본 거리 대비 앞으로 나간 비율. 0.3 이면 거리 70%.

## 2. 변이 (스폰이 일어남)

| 항목 | 값 |
|---|---|
| 때 | `Rose` 이벤트 (적 턴 시작, 시신이 스폰으로 일어날 때) |
| 대상 | 일어나는 칸 |
| 당김 / 가까이 | 0.6 / 0.35 |
| 색 | 화면 채도 -60. 일어나는 동안 들어갔다가 다음 이벤트에서 빠진다 (비네트 없음) |
| 길이 | 변이 대기 1.2초 (1절 2) |

## 3. 연쇄 변이

1. 한 적 턴에 변이가 여럿이면 2절을 칸마다 차례로 한다(일어나는 순서대로).
2. 두 번째부터는 가까이를 0.25 로 줄인다(훑는 느낌). 색은 변이가 다 끝날 때까지 유지한다.

## 4. 적 턴 따라가기

| 항목 | 값 |
|---|---|
| 때 | 적 진영 유닛의 `Walk`, 적이 공격자인 `Hit` |
| 대상 | `Walk` 는 걷는 유닛의 현재 위치(걷는 동안 따라감), `Hit` 는 공격자와 표적의 가운데 |
| 당김 / 가까이 | 0.3 / 0.1 (살짝만. 보드 대부분이 계속 보여야 한다) |
| 끝 | 다음 적 행동이 오면 그 대상으로 옮겨 가고, 플레이어 턴 배너에서 기본 시점으로 돌아온다 |

아군 행동(플레이어가 명령한 이동·공격)은 따라가지 않는다. 플레이어가 이미 보고 있는 곳이다.

### 4-1. 묶음 이동 (#140, 1단계)

규칙은 지금처럼 적을 하나씩 결정한다(docs/systems/ai.md 1). 재생만 묶는다.

| 항목 | 값 |
|---|---|
| 묶는 것 | 이벤트 목록에서 **바로 이어진** `Walk` 들. 사이에 다른 이벤트(타격·함정·창 찌르기·팝업 등)가 끼면 거기서 끊는다 |
| 겹침 검사 | 묶음 안 걷기들의 출발 칸·경로 칸이 하나라도 겹치면 그 걷기부터 새 묶음 (앞 적이 비운 칸을 뒤 적이 지나가면 동시에 걸을 때 겹쳐 보임) |
| 재생 | 묶음 안 걷기를 동시에 시작해 모두 끝날 때까지 기다린다 |
| 카메라 | 묶음이 둘 이상이면 걷는 적들 위치의 평균을 따라간다. 당김·가까이는 4절 그대로 |
| 발소리 | 묶음의 첫 걷는 유닛만 낸다 |

### 4-2. 이동 먼저 (#140, 2단계)

규칙은 여전히 적을 하나씩 결정한다(이동 → 공격 → 다음 적). 재생 순서만 바꿔 **걷기를 앞 적들의 공격보다 먼저** 보여 준다. 4-1 묶음은 앞당긴 뒤에 고른다.

| 항목 | 값 |
|---|---|
| 앞당기는 것 | 적 걷기. 그 앞에 있는 공격 쪽 이벤트(로그·타격·체력·팝업·죽음·시신)를 건너 앞 걷기들 바로 뒤로 간다 |
| 넘지 않는 것 | 배너, 도착, 변이(일어남), 문 열림, 깨어남, 달, 늑대 변신, 수습. 그리고 앞당기지 못한 걷기 |
| 제자리에 두는 걷기 | (1) 건너뛸 이벤트 중에 그 걷는 유닛이 나온다 (2) 건너뛸 죽음·시신 칸이 그 걷기의 출발·경로 칸이다(죽은 자리로 들어가는 길) (3) 걷기 바로 뒤에 그 유닛이 당하는 반응(함정·창 찌르기)이 붙어 있다 |
| 제자리 걷기 뒤 | 그 걷기와, 그 유닛이 당하는 뒤 이벤트는 넘지 않는 벽이 된다. 뒤 걷기는 그 뒤로만 앞당긴다 |

규칙이 앞 적의 공격 결과(누가 죽었나)를 보고 고른 길이라도, 칸이 안 겹치면 먼저 걸어도 어색하지 않다고 본다. 어색하면 제자리 조건을 늘린다.

## 5. 보름달 흡혈

### 예고 (플레이어 턴)
1. 흡혈 표적이 새로 정해진 직후(다음 적 턴에 보름달이 차서 표적이 생긴 때), 재생이 끝나면 뱀파이어와 표적의 가운데로 2초 당겼다가 돌아온다.
2. 당김 / 가까이: 0.4 / 0.15. 비네트 없음. 이 동안에도 입력은 막지 않는다.
3. 같은 표적에는 한 번만 한다.

### 실행 (적 턴)
1. 보름달 배너(`banner.fullMoon`)가 뜨면 뱀파이어와 표적의 가운데로 당긴다. 당김 / 가까이: 0.5 / 0.25. 비네트 없음.
2. **흡혈 모션**(흡혈 타격): 당김 / 가까이 0.6 / 0.35, 붉은 비네트를 강하게(세기 0.6, 부드러움 0.7, 색 MoonBlood) 넣는다. 흡혈 타격 대기는 일반 타격보다 1.6초 더 길다. 표적이 쓰러지면 비네트가 빠진다.
3. 흡혈이 실패하면(표적이 빛 안·멀리) 비네트 없이 1번 당김만 하고, 뱀파이어는 4절대로 따라간다.

## 6. 타격 흔들림과 짧은 멈춤

1. **큰 공격에서만** 화면을 흔들고 아주 짧게 멈춘다(멈춤 = 게임 시간 정지). 기본 공격에는 흔들림·멈춤이 없다.
2. 큰 공격 = 피해 **4 이상**인 타격, 또는 흡혈. 기준점 근거: 지금 데이터의 보통 피해는 1~3 이고, 기사, 돌격, 사냥꾼의 언데드 추가피해, 방어가 낮은 아군을 치는 뱀파이어 공격이 4 이상이다.
3. 큰 공격: 흔들림 세기 = 기본 거리의 0.6%, 0.4초에 걸쳐 줄어듦. 멈춤 0.09초.
4. 흔들림은 화면 가로·세로로만, 고정된 사인 모양(무작위 없음). 재생 템포(1절 2)와 상관없이 실제 시간으로 잰다.
5. 설정 창의 "화면 흔들림"(끔·약하게·보통 = 0·0.5·1)을 세기에 곱한다 (docs/ui/settings.md 6).

## 7. 중요한 처치 줌

1. 뱀파이어·스폰이 쓰러질 때(`Died`), 그 칸으로 당긴다. 당김 / 가까이 0.5 / 0.3.
2. 쓰러진 뒤 1초(0.5초 × 템포 2배) 더 머문 다음 다음 재생으로 간다.
3. 하수인(해골)·아군이 쓰러질 때는 하지 않는다. 마지막 처치는 9절이 대신한다.

## 8. 전투 시작 훑기

1. 전투 화면이 열리면(배치 단계 시작) 카메라가 뱀파이어 가까이(당김 / 가까이 0.7 / 0.35)에서 시작해 1.4초 머문 뒤, 맵을 지나 기본 시점으로 내려앉는다(감쇠 0.6초).
2. 그 사이 마우스 버튼이나 키를 누르면 바로 기본 시점으로 돌아간다(배치 클릭이 어긋나지 않게).

## 9. 승리·패배 마무리

1. 전투를 끝내는 마지막 일격(뱀파이어를 쓰러뜨리는 타격, 또는 마지막 아군을 쓰러뜨리는 타격)에서 게임 시간을 0.35배로 1.6초(실제 시간) 늦춘다.
2. 그 표적으로 당긴다: 당김 / 가까이 0.8 / 0.45. 쓰러진 뒤 2초 더 머문다.
3. 전투가 끝난 뒤(결과 화면)에도 카메라는 그 자리에 머문다.
4. 이때는 6절의 멈춤을 하지 않는다(느린 화면이 대신한다). 흔들림은 6절대로 큰 공격일 때만 한다.

## 10. 아군 직접 처치

1. 아군을 직접 처치하면(`popup.execute`) 그 아군 칸으로 당긴다: 당김 / 가까이 0.4 / 0.25.
2. 멈춤 0.12초, 그 뒤 1초(0.5초 × 템포 2배) 머문 뒤 쓰러진다.

## 11. 플레이어 시점 조작 (#117)

맵이 커져(20×16 등) 맞춤 시점에서 유닛이 너무 작다. 플레이어가 시점을 옮긴다. 연출(2~10절)은 이 시점 위에 더해지고, 끝나면 이 시점으로 돌아온다.

| 입력 | 동작 |
|---|---|
| 마우스 휠 | 확대·축소. 한 칸에 거리 ×0.85(확대)·÷0.85(축소). 커서 아래 땅이 화면에서 그 자리에 머문다. 가장 멀리 = 맞춤 거리, 가장 가까이 = 맞춤 거리의 0.3 |
| Q / E | 보는 점을 축으로 왼쪽·오른쪽 돌기, 초당 90°. 각도 제한 없음. 기울기(55°)는 그대로 |
| 휠 클릭 끌기 (#120) | 가운데 버튼을 누른 채 가로로 끌면 Q/E 와 같은 축으로 돌기, 화면 1px 에 0.3°. 누를 때 커서가 UI 위면 돌지 않는다 |
| W A S D, 방향키 | 화면 방향으로 평행 이동, 초당 (지금 거리 × 0.8). 보는 점은 보드 칸 범위 밖으로 나가지 않는다 |
| R | 맞춤 시점으로 (거리·각도·위치 모두) |

1. 움직임은 0.12초 감쇠로 따라간다(연출의 0.6초보다 빠르게, 조작이 늦게 느껴지지 않게).
2. 휠은 커서가 UI 위에 있으면 쓰지 않는다. 키는 늘 받는다.
3. 재생 중에도 조작할 수 있다. 연출 끔(settings.md 5)과 상관없다.
4. 새 전투(`BattleView.Begin`)는 맞춤 시점에서 시작한다.
5. 남쪽 둘레를 낮게 둔 규칙(stage-dressing.md 1-5)은 돌린 시점에선 지켜지지 않는다. 가리는 소품은 13절이 숨긴다.

## 12. 정한 세부 (docs/design 에 없는 것)

- 2026-11-19 사용자 결정(#146) "지금 연출을 각도 있는 컷으로": 14절. 스토리 컷신이 아니라 모든 전투에 공통인 카메라 연출. 수치는 위 "드물수록 세다" 를 따라, 한 판에 한 번인 마무리가 가장 세고 자주 나는 적 따라가기·증원 도착·보름달 예고는 돌지 않는다.
- 2026-11-12 사용자 리뷰(#117) "오브젝트 뒤에 유닛이 올 때 오브젝트를 투명화": 13절. Synty 소품 셰이더(Generic_Basic 셰이더 그래프)는 실행 중 투명으로 바꾸려면 머티리얼 사본마다 키워드·블렌드를 바꿔야 해서, 가장 단순한 숨김(그림자만)으로 했다. 반투명이 필요하면 사용자 확인 뒤.
- 2026-11-11 사용자 요청(#117): 맵이 커져 캐릭터가 작아짐 → 확대·회전 추가(11절). 이동은 확대만으로 볼 곳을 못 가므로 같이 넣고, 휠은 커서 쪽으로 다가가게 했다.
- 2026-11-09 사용자 확인(#97): 적 움직임이 빨라 어지러움 → 템포 2배·감쇠 0.6초, 비네트는 흡혈 모션만.
- 수치(당김·가까이·색)는 조사 원칙 "드물수록 세다"에 따라 변이 > 보름달 > 적 따라가기 순으로 세기를 둔다.
- 설정 창의 "카메라 연출" 끔이면 2~5·7~10절과 6절 멈춤을 하지 않는다 (docs/ui/settings.md 5).

## 13. 유닛을 가리는 소품 숨기기 (#117)

1. 대상: 장 꾸미기 프리팹의 `Props` 아래 소품(막힌 칸·둘레 소품). 바닥 지형(`Terrain`)·칸 격자·물·빛 칸 화로는 제외.
2. 때: 카메라에서 살아 있는 유닛(아군·적 모두, 가슴 높이 0.8) 까지의 선분이 소품의 외곽 상자(렌더러 bounds)를 지나면, 그 소품을 숨긴다. 유닛 앞 0.3 은 빼서 유닛 칸에 닿기만 한 소품은 숨기지 않는다.
3. 숨김: 소품은 안 보이고 그림자만 남는다(반투명 아님, 12절). 가리지 않게 되면 바로 원래대로.
4. 속도: 매 프레임 판정, 바로 바뀐다(서서히 사라지지 않음).
5. 고른 유닛을 따로 우선하지 않는다. 모든 유닛을 같이 본다.

## 14. 각도 컷 (#146)

1. 2·5·7·8·9·10절의 당김·가까이 위에 **돌기**와 **낮추기**를 더한다.
   - 돌기: 연출 대상(당김의 대상 점)을 축으로 카메라가 가로로 도는 각도. + 는 위에서 볼 때 시계 방향.
   - 낮추기: 같은 대상을 축으로 카메라 높이각(기본 55°)을 줄이는 각도. 대상이 화면 가운데 쪽에 남는다.
2. 값 (돌기° / 낮추기°):

   | 연출 | 절 | 돌기 / 낮추기 |
   |---|---|---|
   | 변이 (첫 번째) | 2 | 20 / 15 |
   | 연쇄 변이 (두 번째부터) | 3 | 0 / 0 |
   | 적 턴 따라가기 | 4 | 0 / 0 |
   | 보름달 예고 | 5 | 0 / 0 |
   | 보름달 실행(배너) | 5 | 0 / 8 |
   | 흡혈 모션 | 5 | -25 / 20 |
   | 중요한 처치 | 7 | 15 / 12 |
   | 전투 시작 훑기 | 8 | 30 / 15 |
   | 승리·패배 마무리 | 9 | 35 / 25 |
   | 아군 직접 처치 | 10 | -15 / 10 |
   | 증원 도착 (`Arrived`) | 2 | 0 / 0 (당김 / 가까이 0.6 / 0.35 는 그대로) |

3. 돌기·낮추기도 당김과 같은 감쇠(1절 5, 0.6초 ÷ 배속)로 들어가고 빠진다. 연출이 끝나면 0 으로 돌아와 플레이어 시점(11절)이 된다.
4. 플레이어가 Q/E·휠로 돌린 시점 위에 더한다(그 시점에서 더 돈다).
5. 카메라 연출 끔(settings.md 5)·즉시 재생(`speed = 0`)이면 돌기·낮추기도 0.
6. 13절 소품 숨기기는 각도 컷 중에도 매 프레임 그대로 한다.
