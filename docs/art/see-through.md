# 벽 투과 (See-through)

출처: docs/design/map.md "실내 공간을 표현하려면" (커밋 10cea19), 사용자 요청 #145 ("ditter로 해줘")

실내·실외를 오가는 장에서 건물 외곽·높은 소품이 카메라와 판 사이를 막는다. 막는 부분을 점무늬(디더)로 뚫어 판이 보이게 한다. 카메라가 Q/E 로 돌아도 같은 규칙이 그대로 맞는다(어느 벽을 뚫을지 미리 정하지 않는다).

## 1. 대상
- 장 꾸미기 프리팹의 `Props` 아래 모든 메시(건물·벽·나무·바위·소품). 땅(Terrain·바닥 판)·물·유닛·격자는 뚫지 않는다
- 그림자는 뚫지 않는다(구멍이 나도 벽 그림자는 그대로)

## 2. 구멍
| 항목 | 값 | 이유 |
|---|---|---|
| 중심 | 모드에 따라 (2-1) | |
| 높이 | 유닛 발밑 + 0.6 (가슴) | 발밑이면 구멍 위쪽 절반이 바닥에 걸린다 |
| 크기 | 반지름 월드 1.8 (화면 크기는 거리에 따라) | 유닛 하나와 둘레 한 칸이 들어간다. 확대해도 칸 기준 크기가 같다 |
| 모양 | 안쪽 55% 는 다 뚫고, 바깥 45% 는 점무늬로 흩어진다 (4×4 Bayer 디더) | 경계가 칼로 자른 듯 보이지 않게, 반투명 정렬 문제 없이 |
| 앞뒤 | 중심보다 카메라 쪽으로 0.5 넘게 앞에 있는 것만 뚫는다 | 유닛 뒤 벽은 그대로 남아 "벽에 붙어 섰다" 가 읽힌다 |

중심이 없으면(선택 없음, 커서가 판 밖) 그 구멍은 없다.

### 2-1. 모드 (시험 중, 전투에서 T 키로 끔 → 커서 → 유닛 → 타일 순환, 바꿀 때 화면 위쪽에 이름이 1.5초 뜬다, 고른 모드는 다음 전투에도 남는다)
| 모드 | 뚫는 곳 |
|---|---|
| 끔 | 없음 |
| 커서 (기본) | 선택한 아군 유닛, 커서가 가리키는 칸 |
| 유닛 | 판 위 모든 유닛(아군·적) 둘레. 벽 너머 유닛은 늘 보인다 |
| 타일 | 카메라와 판 칸 사이에 있는 것 전부 (바닥 위 0.3 아래는 남는다). 판을 둘러싼 네모 범위로 잰다 (빈 칸 가장자리도 뚫린다) |

시험해 보고 하나(또는 조합)로 정하면 T 키는 지운다.

## 3. 구현 메모
- 셰이더 `VampireSpawn/SeeThroughLit` = URP Lit 복사본에 구멍 판정(`SeeThrough.hlsl`)만 더함. ForwardLit·GBuffer·DepthOnly·DepthNormals 에서 자르고, ShadowCaster 는 안 자른다
- Synty POLYGON 재질(`_Albedo_Map` 가 있는 것)은 장을 열 때 같은 값의 SeeThroughLit 쌍둥이로 바뀐다. Synty 원본 재질은 고치지 않는다
- 코드: `Assets/_Project/Scripts/Game/SeeThrough.cs`, `BoardView.Dress` 가 `Props` 에 붙인다
- 한계: 쌍둥이 재질은 실행 중에 만들어서, 빌드에서는 `_NORMALMAP`·`_EMISSION`·`_ALPHATEST_ON` 셰이더 변형이 빠질 수 있다. 빌드에서 소품이 밋밋하거나 분홍이면 이 변형을 쓰는 재질 하나를 에셋으로 두거나 ShaderVariantCollection 에 넣는다
