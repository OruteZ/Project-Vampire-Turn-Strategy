# 분야별 안내서

분야마다 `docs/areas/<분야>.md` 하나. 그 분야 첫 작업에서 아래 형식으로 만든다.

## 목록

| 분야 | 안내서 |
|---|---|
| 아트 에셋 | [art-assets.md](art-assets.md) |
| 전투 | [battle.md](battle.md) |

## 형식

```markdown
# <분야>

## 경로
- 기획: docs/design/...
- 코드: Assets/Scripts/...
- 문서: docs/systems/...
- 아트/데이터: ...

## 결정
| 결정 | 상태(시험 중/확정 후보) | 날짜 | 출처(이슈·사용자 원문) |
|---|---|---|---|

## 열린 작업
- #이슈번호 ...

## 맡길 때
- 모델: ...
- 함정: ...
```

## 맡길 모델

| 일 | 모델 |
|---|---|
| 설계·기획·리뷰 | opus / fable |
| 정해진 구현·도구·번역 | sonnet |
| 목록·형식·반복 | haiku |

사용자가 정하면 그것을 따른다.
