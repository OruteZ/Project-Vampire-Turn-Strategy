# UI

> 목적: UI 의 역할, 공개할 정보, 정보 밀도, 조작 환경의 방향을 정한다.

## UI 의 역할

- 중요한 정보와 아닌 정보를 구분한다.
- 정보의 중요도에 차등을 두어 구분하고, 가시성을 중시한다.

## 공개할 정보

- 적 유닛의 스펙을 제공한다. 스펙에는 이동력도 들어간다.
- 플레이어가 위험한 타일을 스스로 계산할 수 있어야 한다.
- 위협 범위는 직접 제공하지 않는다.
- 계산 도움(예: 피해량 미리 보기)은 있어도 좋다.

## 정보 밀도

- 정보는 최대한 깔끔하게 보여 준다.
- 많은 정보가 한 화면에 있더라도, 중요도 차등에 따라 분리되어 보이게 한다.

## 조작 환경

- PC 키보드·마우스.

## 넣지 않을 것

- 턴 타임라인 UI. 유닛별 턴이 아니라 진영별 턴 방식이다.
