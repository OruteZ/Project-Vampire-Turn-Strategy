# 무제

## 개요
- 기본 배치 상황에서 유닛이 엉뚱한 방향을 바라보고 있음
- 모델링의 사양이 다른지 해골은 칼을 잡는 오프셋이 엉성함.
- 모든 기사가 칼을 역수로 들고있음. 창병도 그러한지 확인 필요
- 기본적으로 Loot motion을 켜서 애니메이션의 트랜스폼 변경에 저항하지 않아야 자연스럽게 움직이는 느낌이 들 것 같음

## 요구사항

1. Loot Motion을 키는쪽으로 애니메이션 구조를 변경할 것
2. 모든 유닛이 도구를 정상적으로 들 수 있도록 처리.
3. 앞으로 추가할 유닛과 도구 에셋도 적용될 수 있도록 일련의 파이프라인 설립
4. 기본배치에서 유닛이 적방향 (북쪽)을 쳐다볼 수 있도록 함
5. 관짝에 누워있는 뱀파이어가 오프셋이 이상함. 차라리 일어나기 전까지는 모델링 생성자체를 안하고 관만 보여줄 것

## 완료 기준 (선택)

- 무엇을 보면 끝났다고 할지. 비우면 에이전트가 정하고 이슈에 적는다.

## 참고 (선택)

- 관련 파일, 스크린샷, 링크.
