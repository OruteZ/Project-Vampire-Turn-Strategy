# 003. UI 대개편 - 스테이지 선택

## 개요

현재 스테이지를 선택하고자 하는 창에는 큰 UI적 문제가 있다.

1. 한 화면에 보여주고자 하는 정보가 너무 많음 : 
	- 스테이지 목록
	- 유닛 강화
	- 가진 돈 . . . 
웹사이트스러운 레이아웃 디자인때문에 모델링과 같은 게임미학적 요소가 아무것도 보이지 않음.
- 적응형 UI는 그  해상도 비율이 다각적으로 변하는 웹사이트에서는 적합하나 게임에서 각 요소와 버튼 하나하나가 다 적응형으로 커졌다 작아지는 모습은 굉장히 비정상적으로 보임
- UI요소가 화면을 전부 채우도록 하지 않ㄱ고, 게임적 요소가 항상 중앙에 보이고 UI로 띄워주는 정보는 중요하거나 **특정한** 상황 아니면 사이드에 있어야 함
## 요구사항

0. 일련의 모든 작업을 진행하기전, 웹 리서치를 통해서 게임 UI와 각 Scene 레이아웃 배치에 대한 리서치및 통창 파악후 ui-references의 대대적 업데이트. 주요한 레퍼런스 게임은 다음과 같음 :
	1. Civilization
	2. Desperados
	3. baldur's gate 3
	4. 소녀전선 2 : 망명
	5. 파이어 엠블렘 시리즈

1. 정말 필요하다 생각되는 것이 아니라면 적응형 UI 비율의 요소 전부 삭제, ui-style 지침에도 함께 적용
2. 스테이지 선택 Scene을 여러 차등한 레이어로 나눔 :
	1. 스테이지 전경
	2. 스테이지 선택 시 보이는 스테이지 목표설명과 시작 버튼
	3. 클릭시 병사 강화창으로 넘어갈 수 있는 버튼
- 기본적으로 각 자원이나 정보는 각 Scene에서 필요한 경우에만 표기해준다.
- 가장 기본적인 스테이지 전경 요소 제작 : Synty 에셋을 사용해 3D맵을 제작하며, 각 스테이지에 대응되는 지역이 있고 그 지역을 클릭하면 스테이지 정보화면으로 넘어가게 됨
