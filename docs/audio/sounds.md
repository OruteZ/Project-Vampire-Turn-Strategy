# 사운드 목록

> 출처: docs/design 에 사운드 방향이 아직 없다. 사용자 요청(이슈 #105)으로 기획 에이전트가 정한 첫 안. docs/design 에 사운드 방향이 생기면 이 문서를 맞춘다.
> 목적: 준비할 사운드 파일과, 각각이 어느 순간에 나는지 정한다. 구현 기록은 docs/dev/sound.md.

## 1. 원칙

- **무작위 없음** (docs/design/overview.md 원칙). 한 사운드에 변형 파일을 여러 개 넣으면 **차례대로** 돌려 쓴다. 피치·볼륨을 무작위로 흔들지 않는다.
- 톤: 로우폴리 다크 판타지, 밤 전투. 과장된 아케이드 효과음보다 둔탁하고 짧은 소리.
- 파일: `.wav` (또는 `.ogg`), 44.1 kHz. 효과음은 모노, 음악·환경음은 스테레오.
- 효과음은 0.1~1.5 초. 시작에 무음을 두지 않는다 (재생 시점 = 화면 동작 시점).
- 음악·환경음은 끊김 없이 이어지는 루프로 자른다.
- 파일 하나에 사운드 하나. 같은 사운드의 변형은 `<이름>_01`, `_02` … 로 둔다 (권장 개수는 표의 "변형").
- 빠진 사운드는 소리 없이 지나간다. 아래 표를 다 채우지 않아도 게임은 돈다.

## 2. 음악 (루프)

| 칸 | 언제 | 길이 | 느낌 |
|---|---|---|---|
| 음악 > 메뉴 | 메인 메뉴에 들어오면 | 1~2 분 루프 | 고요하고 불길한 테마 |
| 음악 > 야영지 | 원정 지도(장 선택·병영)에 들어오면 | 1~2 분 루프 | 모닥불 곁, 준비. 메뉴보다 따뜻하게 |
| 음악 > 전투 | 전투 화면에 들어오면 (배치부터 끝까지) | 2~3 분 루프 | 긴장, 낮은 타악. 효과음을 가리지 않게 중저음 위주 |

- 화면이 바뀌면 0.5 초에 걸쳐 앞 음악이 줄고 새 음악이 커진다. 같은 음악이면 끊지 않고 이어 간다.
- 전투가 끝나면 전투 음악이 0.5 초에 걸쳐 꺼지고 아래 "끝" 효과음이 난다.

## 3. 환경음 (루프)

| 칸 | 언제 | 느낌 |
|---|---|---|
| 환경음 > 전투 | 전투 화면 내내, 음악 아래 | 밤바람, 먼 개 짖음 없이 바람·풀벌레 |
| 환경음 > 야영지 | 원정 지도 내내 | 모닥불 타닥임, 바람 |
| 화로 (`화로 불`) | 전투 맵의 화로 칸마다, 그 자리에서 | 불 타는 소리. 카메라가 가까우면 들리고 멀면 사라진다 |

메뉴에는 환경음이 없다.

## 4. UI

| 칸 | 언제 | 변형 | 느낌 |
|---|---|---|---|
| UI > 누름 | 모든 버튼·카드·탭·지도 표식을 눌렀을 때 | 1~2 | 짧은 나무·금속 딸깍 |
| UI > 올림 | 버튼·카드 위에 마우스를 올렸을 때 | 1 | 아주 작은 스침. 누름보다 훨씬 작게 |
| UI > 안 됨 | 비활성 버튼을 누르거나 전투 명령이 거절됐을 때 (못 가는 칸, 인구·은 부족 등) | 1 | 둔탁한 막힘 |
| UI > 선택 | 전투에서 아군 유닛을 골랐을 때 | 1 | 갑옷 스치는 소리 |
| UI > 배치 | 배치 단계에서 유닛을 칸에 놓았을 때 | 1~2 | 발을 딛는 소리 |
| UI > 강화 구매 | 병영에서 강화를 샀을 때 | 1 | 은화·쇠 울림 |
| UI > 출정 | 원정 지도에서 전투로 떠날 때 | 1 | 북·뿔나팔 한 번 |

## 5. 전투 진행

| 칸 | 언제 (전투 이벤트) | 느낌 |
|---|---|---|
| 전투 > 아군 턴 | "아군 턴" 배너 (전투 시작 포함) | 짧은 금속 울림 |
| 전투 > 적 턴 | "적 턴" 배너 | 낮은 북 |
| 전투 > 관 열림 | 잠든 뱀파이어가 깨어날 때 (관 뚜껑, `Woke`) | 돌 뚜껑 밀리는 소리 |
| 전투 > 보름달 | 보름달 배너 (뱀파이어가 흡혈하는 턴) | 불길한 현악 상승 |
| 전투 > 달 기욺 | 장의사 의식으로 달 단계가 내려갈 때 | 낮은 종 |
| 전투 > 처형 | 아군을 처형할 때 | 칼이 내려치는 짧고 무거운 소리 |
| 전투 > 치료 | 치료할 때 | 부드러운 천·약병 소리 |
| 전투 > 매장 | 시체를 묻을 때 | 삽으로 흙 덮는 소리 |
| 전투 > 흡혈 | 뱀파이어가 흡혈에 성공할 때 | 물어뜯는 소리 + 낮은 숨 |
| 전투 > 흡혈 실패 | 흡혈이 빛·거리 때문에 빗나갈 때 | 쉿 하는 실망 |
| 전투 > 일어남 | 시체가 스폰으로 일어날 때 | 뼈 뒤틀림, 신음 |
| 전투 > 승리 | 결과 창이 승리로 열릴 때 | 3~5 초 짧은 승리 악절 |
| 전투 > 패배 | 결과 창이 패배로 열릴 때 | 3~5 초 짧은 패배 악절 |

## 6. 유닛

유닛 소리는 **모습(UnitLook) 하나마다** 따로 줄 수 있다. 칸을 비우면 "기본" 줄을 쓴다. 스폰(시체에서 일어난 아군)은 무기를 잃었으므로 원래 병종이 아니라 "스폰" 줄을 쓴다.

| 소리 | 언제 | 변형 |
|---|---|---|
| 공격 | 공격 동작이 시작될 때 (공격자) | 2~3 |
| 맞음 | 맞을 때 (맞는 쪽) | 2~3 |
| 죽음 | 쓰러질 때 | 1~2 |
| 걸음 | 이동 중 한 칸 디딜 때마다 | 3~4 |

| 줄 | 모습 | 공격 | 맞음 | 죽음 | 걸음 |
|---|---|---|---|---|---|
| 기본 | (빈 칸 대신) | 칼 휘두름 | 살 맞음 | 쓰러짐 | 흙길 발소리 |
| 스폰 | 일어난 시체 | 손톱 할퀴기 | 살 맞음 | 쓰러짐 | 질질 끄는 발 |
| 검사 | Sword | (기본) | 사슬 갑옷 | (기본) | (기본) |
| 기사 | Knight | 무거운 칼 | 판금 갑옷 | 판금 무너짐 | 무거운 쇠 발 |
| 농민 창병 | PSpear | 창 찌르기 | (기본) | (기본) | (기본) |
| 궁수·농민 궁수 | Archer, PArcher | 활 쏘기 | (기본) | (기본) | (기본) |
| 사냥꾼 | Hunter | 석궁 발사 | 가죽 | (기본) | (기본) |
| 장의사 | Gravedigger | 삽 휘두름 | (기본) | (기본) | (기본) |
| 역병 의사 | PlagueDoctor | (기본) | (기본) | (기본) | (기본) |
| 해골 | Skeleton | 녹슨 칼 | 뼈 부딪힘 | 뼈 무너짐 | 뼈 달그락 |
| 해골 궁수 | SkeletonArcher | 활 쏘기 | 뼈 부딪힘 | 뼈 무너짐 | 뼈 달그락 |
| 중갑 해골 | SkeletonHeavy | 무거운 칼 | 쇠 + 뼈 | 뼈 무너짐 | 뼈 달그락 |
| 뱀파이어 | Vampire | 손톱 할퀴기 | 쉿 하는 비명 | 재가 되어 흩어짐 | (없음, 미끄러지듯) |

`(기본)` 은 그 칸을 비워 둔다는 뜻이다. 우선순위: 기본 줄 → 스폰·뱀파이어 → 기사·해골 → 나머지.

## 7. 준비 우선순위

1. 음악 > 전투, UI > 누름, 기본 유닛 줄 4개 (이것만 있어도 전투가 비어 보이지 않는다)
2. 전투 진행 표 전체, 음악 > 메뉴·야영지
3. 환경음·화로, 병종별 유닛 소리
