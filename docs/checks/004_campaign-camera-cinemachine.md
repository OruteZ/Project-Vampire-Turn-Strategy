# 확인 004: 원정 지도 카메라가 Cinemachine 으로 움직임 (#57)

> dev 최신에서 확인. 결과는 칸에 `x`(됨) 또는 그 줄 끝에 무엇이 달랐는지 적어 보내 주세요.
> 에이전트가 이미 돌린 자동 검사: 컴파일, EditMode 193/193, PlayMode 4/4, 장 선택 화면비 검사(L1·L2 1/8/10장·L3, 6 화면비) 한·영 0 건. L2 에서 고른 지역이 빈 곳 가운데(1920×1080 에서 x 0.35)에 오는 것을 값으로 확인했다.

Menu 씬에서 Play → 캠페인으로 원정 지도(L1)를 연 상태에서 시작합니다.

- [ ] 1. L1 에서 지역 10개 표식이 모두 화면 안에 보이고, 오른쪽 위 버튼과 겹치지 않는다
- [ ] 2. 열린 장 표식을 클릭하면 카메라가 0.3초쯤 부드럽게 그 지역으로 다가가고, 지역이 오른쪽 칸 왼쪽 빈 곳 가운데쯤에 온다 (칸에 가리지 않는다)
- [ ] 3. L2 에서 Esc 를 누르면 카메라가 부드럽게 전경으로 물러난다 (튀거나 끊기지 않는다)
- [ ] 4. L2 에서 ↓/↑ 로 다른 열린 장으로 옮기면 카메라가 그 지역으로 부드럽게 옮겨 간다
- [ ] 5. 병영(B 또는 왼쪽 아래 버튼)을 열면 카메라가 마지막으로 클리어한 지역(없으면 1장) 가까이로 가고, 닫으면 돌아온다
- [ ] 6. 카메라가 움직이는 동안 지역 표식이 지형을 따라 붙어 다닌다 (한 박자 늦게 끌려오지 않는다)
- [ ] 7. 전투에서 이기거나 져서 지도로 돌아오면 카메라가 이동 없이 바로 제자리에 있다
- [ ] 8. (선택) Camp 씬을 열면 `Campaign Map` > `Cameras` 아래 `Shot Wide`, `Shot s1`…`s10`, `Shot Camp` 가 보이고, 고르면 Scene 뷰에서 그 시점을 볼 수 있다
