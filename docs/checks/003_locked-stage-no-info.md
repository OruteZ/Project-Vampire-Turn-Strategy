# 확인 003: 잠긴 장은 장 정보(L2)로 가지 않음 (#48)

> dev 최신에서 확인. 결과는 칸에 `x`(됨) 또는 그 줄 끝에 무엇이 달랐는지 적어 보내 주세요.
> 에이전트가 이미 돌린 자동 검사: 컴파일, EditMode 193/193 (새 시험 `ALockedStageNeverOpensInfo`), 장 선택 화면비 검사 한·영 0 건.

- [ ] 1. 잠긴 장의 표식을 클릭해도 아무 일이 없다 (L1 그대로, 카메라도 그대로)
- [ ] 2. 열린 장의 표식을 클릭하면 지금처럼 L2 가 열린다
- [ ] 3. L1 에서 ↑ 로 초점을 잠긴 장까지 옮길 수 있고, 거기서 Enter 를 눌러도 L2 가 열리지 않는다
- [ ] 4. 열린 장의 L2 에서 ↑ 를 눌러도 다음 장이 잠겨 있으면 그대로 머문다. ↓ 로 앞 장(열림)은 갈 수 있다
