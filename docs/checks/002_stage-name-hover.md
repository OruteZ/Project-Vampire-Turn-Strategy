# 확인 002: 장 선택 지도에서 이름 띠는 호버만 (#47)

> dev 최신에서 확인. 결과는 칸에 `x`(됨) 또는 그 줄 끝에 무엇이 달랐는지 적어 보내 주세요.
> 에이전트가 이미 돌린 자동 검사: 컴파일, EditMode 192/192.

메뉴 → 캠페인으로 원정 지도(L1)를 연 상태에서 시작합니다.

- [ ] 1. L1 에서 아무 표식에도 마우스를 올리지 않으면 이름 띠가 하나도 없다
- [ ] 2. 표식에 마우스를 올리면 그 표식의 이름 띠만 뜨고, 마우스를 떼면 사라진다
- [ ] 3. 표식을 클릭해 L2 로 가면 그 장의 이름 띠가 고정으로 떠 있다
- [ ] 4. L2 에서 빈 땅 클릭(또는 Esc·닫기)으로 L1 로 돌아온 뒤, 마우스를 그 표식에서 떼면 이름 띠가 사라진다 (요청하신 경우)
- [ ] 5. L1 에서 ↑/↓ 로 초점을 옮기면 이름 띠 없이 그 표식 배지만 살짝 커진다
