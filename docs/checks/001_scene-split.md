# 확인 001: 화면별 씬 분리, 원정 지도 굽기 (#46)

> 브랜치 `scene-split` (또는 dev). 결과는 칸에 `x`(됨) 또는 그 줄 끝에 무엇이 달랐는지 적어 보내 주세요.
> 에이전트가 이미 돌린 자동 검사: 컴파일, EditMode·PlayMode 시험, 화면비 검사(sweep). 아래는 사람이 눌러 봐야 아는 것만입니다.

## A. 화면 흐름 (Menu 씬에서 Play)

- [ ] 1. Play → 메인 메뉴가 뜨고 뒤에 흐린 보드가 보인다
- [ ] 2. 캠페인 카드 클릭 → 원정 지도(L1)로 바뀐다. 0.3초 검은 화면에서 밝아진다
- [ ] 3. 지도에서 지역 표식 클릭 → 오른쪽에 장 정보 칸(L2), 카메라가 그 지역으로 간다
- [ ] 4. 칸 밖 빈 땅 클릭 → 칸이 닫히고 지도(L1)로, 초점은 그 장 그대로
- [ ] 5. B → 병영(L3). 다시 B → 원래 레이어로
- [ ] 6. 열린 장의 L2 에서 Enter 또는 출정 → 전투 배치 화면
- [ ] 7. 전투 배치에서 왼쪽 아래 나가기 → 원정 지도의 L2, 같은 장
- [ ] 8. L1 에서 Esc → 메인 메뉴
- [ ] 9. 메뉴에서 데모 전투 → 전투. 나가기 → 메인 메뉴 (원정 지도로 가지 않음)
- [ ] 10. 메뉴 → 캠페인 → 다른 장을 고른 뒤 메뉴로 나갔다가 다시 캠페인 → 마지막에 고른 장에 초점

## B. 씬 하나만 열고 Play

- [ ] 11. `Battle` 씬만 열고 Play → 데모 1장 전투가 바로 시작한다
- [ ] 12. `Camp` 씬만 열고 Play → 원정 지도(L1)가 지금 저장된 진행으로 뜬다

## C. 원정 지도를 손으로 고치기 (2번)

- [ ] 13. `Camp` 씬을 열면(Play 없이) 씬 뷰·Hierarchy 에 `Campaign Map` 아래 지역 10개·숲·바닥이 보인다
- [ ] 14. `Region s3` 안의 소품 하나를 옮기고 씬 저장 → Play 하면 옮긴 자리에 있다
- [ ] 15. `Region s3` 오브젝트 전체를 몇 칸 옮기고 저장 → Play 하면 3장 표식·(클리어했다면) 화로·L2 카메라가 옮긴 자리를 따라간다 (길은 따라가지 않는 것이 맞다)
- [ ] 16. 도구 모음 > 지도 > "Camp 씬에 지도 굽기" → 확인 창이 뜨고, 굽기를 누르면 손으로 옮긴 것이 배치 표대로 돌아간다
